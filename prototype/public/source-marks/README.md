# Series identification artwork

These marks identify the data mission or instrument in the catalogue board. They
do not brand GeoD Global or imply an affiliation, certification or endorsement.
The artwork has its own attribution and usage terms, separate from the code.

JPEG files retain the original downloaded bytes. All images retain their complete
artwork and proportions and are served from this repository without remote image
requests. The board supplies the credits; each mark also has an alt label and
credit tooltip. Failed image loads use a text/Lucide identifier so exploration
remains available.

Landsat, VIIRS, Copernicus DEM, NAIP and HLS use GeoD's own series treatment built
from the existing Lucide icons and ordinary text. These are not official logos.
Landsat 8/9 is deliberately not represented by a Landsat 9-only mission patch.
The Copernicus programme trademark and NASA/USGS/ESA agency logos are not bundled.

See `manifest.json` for the source URLs and file hashes. Review these source terms
again before repurposing artwork for marketing, merchandising or a different use.
