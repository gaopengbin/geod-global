# MODIS 多景质量合成

2026-10-04。MOD09A1 / MYD09A1 v061 的工程科学 RGB 新增多景联合质量选择。每个输出像元的红、绿、蓝必须来自同一份完整且合格的原始影像；较新的合成时段优先，新景有云、质量不合格或缺少任一 RGB 波段时，保留较早的合格整组三通道。没有合格完整候选时，三个通道均为 `-28672` NoData。

## 软件操作

1. 在同一工程下载每景的红、绿、蓝、波段质量和像元状态五份原文件。
2. 对五类文件使用相同工程区域生成处理结果，矩形和带孔多边形均可。
3. 从工程的本地 RGB 组合选择「生成科学 RGB」，选择「剔除云与云影标记」或「晴空且 RGB 波段质量最佳」，按需勾选「同时剔除雪冰」，填写成果名称后提交。
4. 打开成果检查地图与原值。文件详情中的「原始景选择与来源」保存各景最终保留的像元数、质量回退数、五份原文件链接和完整校验值。

五类处理结果用来确定完全相同的区域、网格和有序场景清单。合成重新读取五份原件，联合选择场景，不使用五份独立拼接结果的像元值。缺少任何一景的原文件或匹配质量结果时，不能提交质量筛选；默认的「保留全部原始值」行为保持原有规则。

## 规则与成果

质量规则沿用[同景筛选](modis-rgb-quality-mask.md)。顺序按合成时段开始日期排列，同日按完整条目 ID 稳定排序；较后的合格完整候选覆盖较早候选。每景的 RGB 与 QC / State 都绑定精确条目、波段、完整 SHA-256、原始 URL、源网格和标定。最多 32 景，保持源正弦投影、像元间距和工程像元对齐，无重采样、重投影、平均或大气精度保证。负值、有效零及超过 1 的反射率不因数值范围而被剔除。

多景保存 `geod-modis-rgb-mask/v2`，包含 `coupled.scenes` 的全部五层来源、各景网格、固定选择规则及完整工程几何。原来的同景成果仍使用 v1；没有质量规则的成果规格和交付内容保持兼容。CLI、HTTP、Tauri 和 MCP 沿用[统一科学 RGB 请求](scientific-rgb.md)，无需提交原文件路径或新授权字段。

计数必须区分：

- `sceneValidPixels`：各景最终贡献的完整合格 RGB 像元，合计等于三个通道共同有效数。
- `fallbackPixels`：较新的完整 RGB 候选未通过质量规则，最终保留较早合格候选的像元。新景缺波段而回退不一定增加这个数，因为它不是完整候选。
- `inputCommonValidPixels`：质量选择前至少有一景完整 RGB 的像元数，不能用三个独立波段拼接的共同有效数代替。
- `removedValidPixels`：本来有完整候选、筛选后没有合格完整候选的像元数。
- `rejectedPixels`：整个输出网格中没有合格完整 RGB 的像元数，包含原先无效、未覆盖以及几何区域外的像元；界面使用「无合格 RGB 的像元」说明。

任务读取和交付包校验全部来源与结果。生成完成后，成果 TIFF、完整规格和清单可以独立读取与打包，移走父级记录不会触发重新下载。缩略图沿用持久化缓存，读取缓存前仍校验成果身份。

## 实际文件验收

本轮使用此前已经由软件下载的 15 份公开 COG，三景为 `MYD09A1.A2025169.h08v05.061.2025178155736`、`MYD09A1.A2025177.h08v05.061.2025189031924` 和 `MYD09A1.A2025177.h09v05.061.2025189031843`。验收副本采用不可达上游代理，未新增供应商下载或账号正向授权证据。

真实云区回退的矩形窗口为 92 × 20；`clear` 保留较早影像的 1,454 个像元，`clear_best` 保留 163 个，三个通道一起回退且原值不变。带孔窗口的两种规则分别回退 976 和 103 个像元。实际雪冰选项没有额外变化，不将其作为真实雪冰剔除的正样本。

云区矩形、云区带孔范围、相邻瓦片矩形及三景带孔范围分别验证 `clear`、`clear_best`、`clear_best + excludeSnow`，共十二份成果。全部 **69,120 个通道值**、**23,040 个预览 RGBA 像素**和 33 个原值点均由 Rasterio / GDAL、NumPy、Shapely 独立核对；各景贡献数、回退数、全通道摘要、源 CRS 参数、精确仿射网格、标定及十二份 ZIP 成员 / CRC 通过。相邻瓦片窗口没有质量回退，不将它冒充该正样本。三十份既有源 / 处理文件的摘要和修改时间不变。

实际 stdio MCP 的直接目录与本地服务两种模式共核对 11,040 个通道值，断开后重新连接、只读写入拒绝及错误规则控制通过。移走全部 35 个原件 / 中间处理父级记录与文件后，十二份成果仍可检查、原值读取及导出；缩略图的全部 23,040 个 RGBA 像素一致，十二个缓存条目在重启后保持字节、文件身份和创建时间。修改成果、改变规则清单和损坏缓存的控制也通过。

三个界面视口覆盖英文亮色 1440、中文暗色 1024 和英文暗色 900 像素。实际按钮完成新的多景生成，名称、预检规则、场景来源和输出摘要与独立文件验收一致；地图实际绘制的源预览共 5,680 个 RGBA 像素与原生预览一致，来源详情包含各景五份原件。没有横向溢出、脚本错误、CSP 违规或外部请求，截图已检查。此处未逐像素比较缩放后的地图画布，也不代替原生 WebView 人工验收。

完整机器记录见[多景验收](../prototype/qa/modis-coupled-verification.json)。科学 RGB 原生回归 7 项、质量读取 4 项、实际 Windows CLI 子进程 1 项、前端逻辑 9 项及交互 9 项通过；缺波段、负值 / 零 / 大于 1、单独质量位、改变来源、取消和移除父级的情况另用标明的合成文件验证，不冒充供应商原件。同景及不筛选编码结果另以 6,720 个实际通道值核对兼容。前后两版完整 renderer、桌面开发二进制和四份原始验收记录按 SHA-256 保存；更新的桌面开发程序为 80,518,656 字节，摘要 `6480c7c0eb2db32ff7d0de04f2a882ae7a95fef7204f02b271da7c06e3bdea0a`。

## 复现与边界

以下命令只写新建的私有目录。同一目录不能同时由直接 MCP 与运行服务拥有；界面测试使用生产资源、精确桌面 CSP 和隐藏 Edge 中的真实原生接口桥接，不操作用户桌面。

```text
python -X utf8 scripts/verify-modis-coupled.py --root .verification/modis-coupled-new --exe .verification/naip-native-target/debug/geod-runtime.exe
python -X utf8 scripts/verify-modis-rgb-mask-mcp.py --root .verification/modis-coupled-new --port 4623
node scripts/verify-modis-rgb-mask-ui.mjs .verification/modis-coupled-new
python -X utf8 scripts/verify-modis-rgb-mask-cache.py --source .verification/modis-coupled-new --root .verification/modis-coupled-offline-new --port 4627
```

尚不包含逐像元来源索引文件、更多产品质量规则、任意网格 / 投影处理或大气校正。其他 MODIS 产品和 Landsat / HLS / VIIRS 的 QA 仍需分别实现。原生 Windows WebView / 安装版人工验收另行进行；没有可用账号时保留软件内 Earthdata / Copernicus 授权入口和生产原文件待验收状态。本轮不制作安装包或远程发布。
