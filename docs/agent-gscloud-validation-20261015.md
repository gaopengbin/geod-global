## 检索消耗变化

对比同一数据云检索任务：

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 模型请求 | 7 | 3 |
| 工具调用 | 8（含无关目录和 STAC 查询） | 2（数据云检索、详情） |
| 输入 token | 99,976 | 30,940 |
| 输出 token | 2,275 | 649 |
| 合计 token | 102,251 | 31,589 |
| 输入缓存 token | 72,448 | 29,568 |
| 观测耗时 | 16.80 秒 | 6.17 秒 |

合计 token 减少 **69.11%**。总量包含已缓存的输入 token，因此请求负载的减少不只是缓存折扣。两次运行都命中提供方缓存，这是一项任务的观测值，不能作为冷缓存费用或所有任务耗时的保证。

主要调整：数据云独立工具组按当前来源预加载；每次请求携带有长度限制的最新界面观测；产品支持精确 ID；工具记录保留产品 ID、分页和下载能力字段。Home 会话不注入工作区观测。
