# Landsat 怎么批量下载？用北京昌平区域，实测 3 期影像、9 份原始波段

![本地 Landsat 真彩色与原始像元检查](https://geod-global.laogao.xyz/assets/cases/landsat-20261023/result.png)

前面有读者问：**想按区域批量下载 Landsat，不想一景一景点，怎么做？**

这次直接用 GeoD Global 的 Windows 桌面版跑一次：选区域、筛日期、多选场景、确认下载，再打开本地成果。实测日期为 2026 年 10 月 23 日，使用软件 0.2.1；渠道统计的补充在后续分发包中单独验证。

结果是 **3 期 Landsat 8/9 影像，9 份 B4/B3/B2 原始 GeoTIFF，共 798,438,650 字节，约 761.45 MiB**。9 个文件全部下载成功，也逐个完整解码并核对了 SHA-256。

我参与开发这个开源软件。本文按实际操作写，不把“搜到了”“加入队列”或“地图看到了”当作下载完成。界面截图来自实机；视频的检索与确认部分是同条件复演，任务记录和成果来自这次真实下载，传输等待过程没有完整保留。

## 1. 先选这条 Landsat 渠道

打开「探索」，点击数据产品选择器，选择 **Landsat 8 / 9**。本例使用 **Landsat · Planetary Computer**，数据是 USGS Landsat Collection 2 Level-2。

这次从检索到下载，没有登录 USGS，也没有配置 Earth Engine。这个结论只针对本文这条渠道和这次实测；不要据此认为所有数据源都免账号、永远可达或没有服务限制。

## 2. 设置区域、日期和云量

![本例的范围、日期与云量设置](https://geod-global.laogao.xyz/assets/cases/landsat-20261023/filters.png)

点「筛选」，本例使用以下参数：

| 项目 | 参数 |
| --- | --- |
| 搜索范围 | WGS84 矩形，西、南、东、北依次为 `116.05, 40.10, 116.35, 40.35` |
| 日期 | 2026-09-01 至 2026-10-23，界面按 UTC 标注 |
| 整景云量 | 0%–20% |
| 本次结果 | 7 景 |

这是昌平区域内的一块示例矩形，**不是昌平区行政边界**。也可以用地图选区。日期、云量和数据供应情况会变化，换地区或换时间不保证还是 7 景。

这里筛的是**整景云量**。即使显示 0.04%，也不能直接认定你的研究区完全无云；分析前还要结合质量波段检查云、云影和有效像元。

## 3. 多选三期，再确认下载内容

勾选以下三景，它们的路径/行号均为 **123/032**：

| 日期 | 场景编号 | 目录中的整景云量 |
| --- | --- | --- |
| 2026-09-13 | LC09_L2SP_123032_20260913_02_T1 | 0.12% |
| 2026-09-21 | LC08_L2SP_123032_20260921_02_T1 | 1.99% |
| 2026-10-07 | LC08_L2SP_123032_20261007_02_T1 | 0.04% |

![批量下载确认：3 景、9 个源文件](https://geod-global.laogao.xyz/assets/cases/landsat-20261023/confirm.png)

点击「保存与下载」：

1. 下载范围选「全部待下载影像 · 3 景」。
2. 给工程起一个方便查找的名字，例如「昌平 Landsat 三期批量下载实测」。
3. 下载内容选「红、绿、蓝三个原始波段 · 30 米 · UInt16」。
4. 核对显示「3 景影像 · 9 个源文件」后，再点「确认并下载」。

这里的红、绿、蓝分别对应 **B4、B3、B2**。每景下载 3 个独立源波段，三景共 9 个文件。**这不是全部波段产品包，也不是按选区裁好的影像。** 搜索方框用于寻找相交场景，本例下载保留完整源场景及其原始网格。

## 4. 看到文件完成，再看成果

![本次真实任务记录：9 个文件全部完成](https://geod-global.laogao.xyz/assets/cases/landsat-20261023/tasks.png)

进入「任务」，选择本例工程，在历史记录里核对下载结果。再到「我的数据」打开同一个工程，检查每景的波段是否齐全。

本次独立检查得到：

| 检查项 | 实测结果 |
| --- | --- |
| 文件数 | 9 / 9 成功，均为本次新传输 |
| 总大小 | 798,438,650 字节 |
| 格式、类型 | GeoTIFF，单波段，UInt16 |
| 坐标系 | EPSG:32650，WGS84 / UTM 50N |
| 像元间距 | 30 × 30 米 |
| 网格大小 | 7761 × 7881 或 7761 × 7891，随场景而异 |
| 完整性 | 逐文件 SHA-256 与任务记录一致，全部数据块可解码 |

这些检查能证明本次文件已完整落地、可读取，**不等于已经完成科学质量评价、精度验证或 QGIS 验收**。

## 5. 打开本地真彩色，区分显示和数值

在工程内选择「打开本地真彩色」，软件把同景 B4/B3/B2 组合显示在地图上。再点「查看像元」，读取原始 DN 和换算值。

本例 2026-10-07 场景中，从 0 开始计数的列 3620、行 3780，读取到：R = 10181、G = 9894、B = 8884。独立读取源文件也核对了这个位置。

Landsat Collection 2 Level-2 地表反射率按 **DN × 0.0000275 − 0.2** 换算；填充值 0 不能直接当作有效反射率使用。这个规则可对照 [USGS 官方说明](https://www.usgs.gov/faqs/how-do-i-use-a-scale-factor-landsat-level-2-science-products)。显示拉伸只改变看起来的明暗，不会把下载的原始 DN 改成显示颜色。

如果要做 NDVI，需要近红外等对应波段；如果要筛云，需要质量波段。本教程只验证三个可见光源波段的批量下载与本地检查。

## 第一次使用，建议这样试

先用同样的范围和时间选 **1 景**，确认能下载并打开，再增加日期和区域。外部渠道速度和可用性会受网络、临时授权和服务状态影响，没有承诺固定下载速度。
