# 本地 PMTiles 导入与离线查看

2026-10-03。补齐 [PMTiles 区域提取](pmtiles-offline.md)的本地文件入口；当前支持 PMTiles v3 的 MVT 矢量瓦片，内部与瓦片压缩为未压缩 / gzip。

## 操作

在“我的数据 → 离线瓦片”点击“打开瓦片文件”。桌面版使用本机文件选择窗口，不向页面暴露任意文件读取路径。导入会校验整个文件、目录及每个瓦片，并将完整输入文件复制到软件数据目录；取消选文件不新增记录，失败不会登记完成包。之后可以删除或移动原输入文件，受管副本仍可打开。

重复打开相同文件名、相同完整内容时，校验并复用已有完好副本，不累积重复卡片；名称或内容不同则保留独立记录。

卡片的三个图标分别打开地图、导出和来源详情。地图可以选择图层、点击要素查看属性；保留已有的本地预览样式、明暗主题和可调整宽度的详情面板。来源详情显示输入文件名、导入时间、保存方式、完整 SHA-256、元数据署名及瓦片清单，不把本地导入伪装成网络来源。

限制为每个输入文件 128 MiB、512 个已寻址瓦片、缩放级别不超过 24。稀疏目录和重复内容 / 连续 TileID 的游程编码均可导入；零值的未知计数按规范进行完整扫描，非零计数必须与实际目录一致。叶目录递归、解压、图层属性与几何均有资源限制。当前不支持栅格 PMTiles、其他压缩或超出这些限制的完整全球文件；[MBTiles](mbtiles-local.md) 通过同一入口使用独立数据库读取器。

## 保存、恢复和导出

本地包仍登记在 `tiles.json`，保存于受管 `tiles/<UUID>.pmtiles`。`source.local` 记录文件名和整个输入文件的 SHA-256，网络 URL / ETag 为空；本地文件不会进入可刷新或联网提取的来源连接列表。旧的网络包记录无需迁移，原来源指纹和导出内容保持兼容。

导入文件的每一个字节保持不变，包括原元数据和压缩瓦片。检查核对全文件校验值；地图逐瓦片核对压缩字节、解压后的图层摘要，浏览器解码前再次核对原始 MVT 校验值。

ZIP 导出包含完整输入 `tiles.pmtiles`、`source.json`、`README.txt` 和 `checksums.sha256`。GeoD 不添加输入文件的本机绝对路径；生产者元数据原有的路径字符串仍按原文件保留。PMTiles 数据的归属与使用条件仍来自具体来源，MVT 也仍有量化、简化、缓冲区和跨瓦片 / 级别重复的性质。

原生 CLI：

```text
geod-runtime tile-packages open --file region.pmtiles --data-dir ./local-data
geod-runtime tile-packages inspect --id UUID --data-dir ./local-data
geod-runtime tile-packages export --id UUID --out region.zip --data-dir ./local-data
```

开发浏览器适配以限定大小的文件字节上传到本机服务，不接受本机路径参数。写操作遵守现有来源 / 客户端请求边界；桌面版共用原生导入器。

## 验收

使用此前实际获取并独立核对的两个公开数据区域包作为本地输入，未重新标作整个全球归档下载：

- Protomaps OSM 区域：3 个瓦片，193,343 字节，SHA-256 `a063c10a20b9e2a60e77edfaeedd666524a51f84d94944349e84c4a6717b513b`。跨级别 2,100 个要素记录，此数不是唯一对象数。
- 邮政区区域：4 个瓦片，550,666 字节，SHA-256 `e443032316abbb83553ecc539502ee0d42cf4f5584192dd323f96c96b16f4a3f`。跨级别 5,601 个记录。

原生 CLI 导入中文 / 大写扩展名的输入文件；独立 `pmtiles 3.8.1` 和 `mapbox-vector-tile 2.2.0` 核对完整文件、所有坐标、瓦片字节、图层摘要、导出内容及校验清单。移除验收用原输入副本后，重启与拒绝源代理下重新核对，已保存文件和完整导出 ZIP 一致。两次真实界面导入也纳入同一独立读取验收。

1440 像素浅色英文、1024 像素深色中文界面实际执行文件导入、错误文件拒绝、来源详情、地图图层筛选和道路属性查看；外部请求被阻断，未使用用户桌面。旧网络提取的 7 个已有包另行复验原来源记录、瓦片及完整 ZIP 兼容。

稀疏 / 游程 / 叶目录 / 未知计数使用明确标注的合成夹具测试，3 MiB 的开发上传上限验证也是合成容器，不当作额外生产数据验收。没有进行安装版 WebView 或本机文件选择窗口的人工验收。

证据见 [验收记录](../prototype/qa/pmtiles-local-verification.json)；可重复独立读取器为 [verify-pmtiles-local.py](../scripts/verify-pmtiles-local.py)。这些 Python 包仅用于验证，不是产品依赖。
