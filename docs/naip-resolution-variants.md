# NAIP 分辨率与历史 TIFF 变体验收

2026-10-04。本轮补齐 0.3 / 1 米路径和真实文件兼容，保留既有[0.6 米验收](naip-inspection.md)。三份完整官方原文件、五份工程结果、全部四通道结果值、离线重启 / 缩略图、MCP 和实际界面处理按钮均已通过；证据仅覆盖下述具体文件与网格。

## 资产身份和通道

[官方 NAIP 集合](https://planetarycomputer.microsoft.com/api/stac/v1/collections/naip)声明 0.3 / 0.6 / 1 米分辨率。路径可以使用 `030`、`060`、`100` 或历史 `1` 标记；`1` 是 1 米，不能除以 100 后显示为 0.01 米。州、年份、网格、象限、UTM 分区、日期及目录分辨率须一致，随后原生下载再向官方请求完整 Item，并核对原始无签名资产和 RGB / NIR 通道角色。恢复工程保留完整官方 ID 和原始日期，第二个日期的含义不作猜测。

两景真实 1 米原文件均为 UInt8 × 4、EPSG:26917、Deflate / 水平预测器、512 × 512 瓦片，无数值 NoData。实际 TIFF 第四通道标签为 ExtraSamples=2，GDAL 将它报告为 alpha；官方条目却明确按 red / green / blue / nir 定义四通道。USDA 的[四通道说明](https://www.fsa.usda.gov/sites/default/files/documents/fourband_infosheet_2017.pdf)和 [Planetary Computer 示例](https://planetarycomputer.microsoft.com/docs/quickstarts/storage/)也采用 RGB / NIR 顺序。

适配器仅对这种已审核的历史 `1` 标记原文件按官方角色读取 NIR。四通道原值及源文件标签不改写，不进行 RGB 预乘；原文件显示 PNG 的 alpha 独立置为 255。通用 TIFF alpha 或其他 NAIP 分辨率的冲突标签不自动归入此规则。派生结果把 NIR 标为未指定的额外采样，并用独立内部掩膜表示覆盖与孔洞。

## 当前边界

NAIP 的下载、原文件处理校验和缓存身份检查统一采用 4 GiB 上限，主网格边长上限 40,000 像素。普通源的原有上限和工程输出像元限制保留。既有 0.6 米的实际处理与重启证据保留，本轮不声称所有美国航摄场景、编码或跨网格组合均已验收。

本页的分辨率矩阵以自然色为显示验收范围；后续自然色 / 红外假彩色 / 近红外切换与独立原值、覆盖掩膜检查另见[显示方式](naip-display-views.md)。安装版 WebView、重投影、任意跨网格拼接及科学标定尚未验收或实现。目录夹具与头部请求用于回归身份规则，不能当作完整原文件下载。原文件不打入应用，没有安装包或远程发布。
