# MODIS v061 十二图层：辅助科学层接入与实际验收

2026-10-04。MOD13Q1 / MYD13Q1 的 Planetary Computer 入口现在支持全部十二个科学 COG：既有 NDVI / EVI，以及新增的质量标记、像元可靠性、观测日序、四种反射率与三种角度。本次新增十层完成实际下载、工程恢复、本地地图与原值、独立裁剪 / 拼接、持久缩略图和两种只读 MCP 验收。[机器记录](../prototype/qa/modis-science-verification.json)

这是公开转换 COG 的接入，不包含完整 NASA HDF；本页的十种辅助层仍独立处理。后续指数的[联合质量筛选](modis-vegetation-quality.md)另有验收，不将其选景结果直接套到辅助层。十二种图层与来源定义见[公开集合](https://planetarycomputer.microsoft.com/api/stac/v1/collections/modis-13Q1-061)。原有两个指数的单独验收记录见[NDVI / EVI](modis-vegetation-indices.md)。

## 软件内使用

探索页选择 MODIS NDVI / EVI 数据源，创建工程或继续向当前工程添加影像。下载入口默认 NDVI + EVI，可选择某一种辅助图层，也可选择全部十二种 COG。返回探索页保留工程身份与科学图层信息。

工程详情用一个科学图层选择栏提供十种辅助层的下载、进度和裁剪 / 拼接操作。无需展开十组重复卡片。文件列表支持缩略图和科学图层筛选；工作空间点击地图可读取完整文件的原始 DN、单位、观测日期或质量位解释。

## 科学含义

下表来自 v061 产品指南，并已与三个实际源条目的 TIFF 类型、填充与元数据核对。角度和反射率换算只影响显示与返回值；保存、裁剪和拼接保留原 DN。[NASA v6.1 用户指南，表 1 / 4 / 5](https://lpdaac.usgs.gov/documents/621/MOD13_User_Guide_V61.pdf)

| 图层 | 原始类型 | 填充值 | DN 换算与有效范围 |
|---|---|---:|---|
| VI 质量标记 | UInt16 | 65535 | 原始 16 位；MODLAND、可用性、气溶胶、邻近云、BRDF、混合云、陆水、冰雪和阴影九组解释 |
| 像元可靠性 | Int8 | −1 | 0 良好、1 边缘质量、2 冰雪、3 云；保留有符号原值 |
| 像元观测日序 | Int16 | −1 | 年内 1–366；结合源文件年份与实际闰年转换为日期 |
| 红光 / 近红外 / 蓝光 / 中红外反射率 | Int16 | −1000 | DN × 0.0001；有效 DN 0–10000 |
| 观测天顶角 / 太阳天顶角 | Int16 | −10000 | DN × 0.01 度；有效 DN 0–18000 |
| 相对方位角 | Int16 | −4000 | DN × 0.01 度；有效 DN −18000–18000；先判断填充，再判断范围 |

原始 COG 的 HDF 元数据继承了除数写法：反射率 `scale_factor=10000`、角度 `scale_factor=100`。软件按上述乘数换算，派生 TIFF 使用 GDAL 的乘数 scale；不将 10000 或 100 当成乘数。VI 可用性位字段中未定义的代码明确显示“未定义代码”，不归入良好质量。

图层保留标称 250 米产品身份；实际 PixelIsArea 正弦网格间距约 231.656358264 米，网格间距从文件读取。观测日期来自该像元的日序，不使用合成周期开始日期替代。跨年份日序拼接会失去年份含义，因此软件拒绝此种拼接，并提示按年份分别处理。

颜色仅用于显示：质量层显示 MODLAND 两位，可靠性显示四级，其余辅助层按各自固定范围灰度显示。原始 NoData 透明；范围外原值仍可读取。统计明确标记为预览采样，`countsFullResolution=false`，不宣称全分辨率质量统计。各层独立采用较新非 NoData 值，较旧有效值补齐缺失；质量文件中的云标记不会自动筛掉其他图层，独立拼接结果不保证同一观测来源。

## 实际证据

原生下载了 Terra h08v05、Aqua h08v05 与相邻 Terra h09v05 的三十份完整辅助 COG，共 **614,859,716 字节**。每份 4800 × 4800，校验字节数和 SHA-256；后续验收复用原件，不重复计为新下载。

独立 GDAL / Rasterio、NumPy、投影与几何工具读取 **691,200,000 个原始 DN**，核对四种范围下四十份成果的全部 **552,960 个 DN**、**19,274,380 个预览 / 缩略图 RGBA 像素**和 372 个原值点。范围包括单景、相邻瓦片、带孔多边形和跨日期重叠。真实补齐范围中，可靠性有 71 个像元、观测日序与红光反射率各有 104 个像元来自较旧 Aqua；各层保留独立选择的语义。

三十三项错误类型、比例、填充、日期、坐标系与通道控制均拒绝创建工程。离线重启恢复七十份原件 / 成果，磁盘缓存文件未重新生成。移除三十份原件后，四十份成果在冷启动和重启后仍能显示、取值与复用缓存；五类损坏缓存可无父级文件重建，改变成果文件后拒绝旧缓存。

直接与本地桥接两种只读 MCP 核对全部七十份栅格和 744 次原值读取，验证写入拒绝、断连拒绝和协议输出。生产界面以 1440 / 1024 / 900 像素视口、中英文和深浅主题实际运行十种图层的处理按钮；输出逐字节等同于独立核对成果，地图真实点击与 GDAL 一致，折叠卡片高度及满高缩略图一致。

探索流程实时获取六条公开记录和六张浏览图，验证十五个来源入口、十四个下载选项、全部十二种科学文件的选择和返回同一工程。此流程只查看入口，新增原文件下载数为零。

原有 NDVI / EVI 六份单景 / 拼接 / 带孔裁剪成果在新运行时再次独立核对，输出字节与旧验收完全相同。270 项前端逻辑、228 项界面回归、475 项原生库测试通过，4 项原生测试明确忽略；4 项桌面测试、严格 Clippy、格式、隔离 / 契约 / 配方检查通过。最后显示文案和工程预览修正后，相关 27 项界面测试再次通过。

Windows 桌面开发程序 **81,090,560 字节**，与经过界面验收的 663 个生产资源一同留存快照；哈希见机器记录。十二项证据汇总反例拒绝通过。现有运行程序和历史指数验收记录保持原有身份。
