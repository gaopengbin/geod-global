# PMTiles 区域提取与离线地图

2026-10-03。当前范围是公开 HTTPS PMTiles v3 中的 MVT 矢量瓦片，支持未压缩 / gzip。依据 [PMTiles v3 规范](https://github.com/protomaps/PMTiles/blob/main/spec/v3/spec.md)实现，未新增产品运行时依赖。

## 软件操作

1. 在探索页选择范围。
2. 打开“我的数据 → 离线瓦片 → 提取离线瓦片”，填写连接名称与公开 `.pmtiles` 文件地址。也可填入公开邮政区样例。
3. 选择来源支持的最小 / 最大缩放级别，查看预计瓦片数量，再保存。
4. 瓦片包卡片提供地图、导出、来源详情三个图标。地图中可选择图层、点击要素查看瓦片属性，调整详情面板宽度。

已有本地 `.pmtiles` 文件可以通过“打开本地 PMTiles”导入受管完整副本，详见[本地导入与验收](pmtiles-local.md)。

按各级别相交的完整瓦片保存，覆盖可超出查询范围。MVT 图形经过量化，可能简化、带有缓冲区、跨瓦片及缩放级别重复，不等同于完整分辨率矢量数据或精确多边形裁剪。地图使用本地预览样式和打包的参考底图，未获取来源样式、字体、图标素材。归属信息按文字显示，原始来源元数据完整保留在导出包中。

支持最多 512 个候选瓦片、128 MiB 保存结果、24 个来源连接、128 个离线包；缩放级别不超过 24。当前为有界同步提取，失败不会登记完成包。源服务须返回准确的 `206 Content-Range` 与强 ETag；后续请求带 `If-Match`，版本改变、截断或无范围支持均拒绝。请求通过源下载代理设置发出；客户端不直接访问远端瓦片文件。目录、解压、MVT 属性索引和几何流均有大小或数量约束。

## 保存与交付

连接、冻结来源和瓦片记录保存在独立工作空间的 `tiles.json`，PMTiles 位于受管 `tiles/` 文件夹；源文件可以移除连接，已有包仍保留冻结来源。检查验证整个包的 SHA-256；地图逐瓦片重新核对压缩字节校验值和图层摘要。

导出 ZIP 包含 `tiles.pmtiles`、`source.json`、`README.txt` 与 `checksums.sha256`。每个瓦片保持原始压缩字节，重新生成的包头、目录和范围元数据使其成为可被标准读取器独立打开的 PMTiles 文件。包保留来源元数据，包括生产工具可能声明的路径字符串；GeoD 不添加本机工作空间文件路径。

PMTiles 是容器格式，不授予数据使用权。Protomaps 全球底图的来源、分发及 OSM 归属要求见 [官方说明](https://docs.protomaps.com/basemaps/downloads)。当前构建地址应从[构建目录](https://maps.protomaps.com/builds/)获取；构建会轮换，不内置假定永久可用的全球文件地址，也不热链在线全球底图供持续显示。

## 实际验收

- 公开邮政区 PMTiles：旧金山区域，级别 4–7，4 个瓦片、550,666 字节结果；三个界面验收流程及调试重跑产生的独立包也全部复核。跨瓦片和级别共解码 5,601 个要素记录，此数不表示唯一对象数。
- Protomaps `20261002.pmtiles`（官方目录当日列出 v4.15.2）：级别 11–13 的旧金山小区域，3 个瓦片、193,343 字节；读取了全球包中的实际叶目录，原数据包括道路、建筑、水域等图层。跨级别共解码 2,100 个记录，不表示唯一对象数。全球文件声明大小 138,538,266,061 字节，并未整体下载。
- 独立 Protomaps Python reader 3.8.1 和 Mapbox MVT decoder 2.2.0 重新读取实际 HTTP 字节范围，验证原压缩瓦片、输出目录 / 坐标、所有图层 / 属性计数、原始 MVT 字节、文件与 ZIP 校验值。验证依赖隔离在忽略的测试目录，不属于软件运行依赖。
- 1440 像素英文浅色 / 1024 像素中文深色的实际连接、区域提取、共享级别选择器、等高卡片、来源详情、导出、地图属性点击通过。OSM 道路筛选与属性点击另用两种主题检查。
- 实际进程重启后，在拒绝外部请求的代理下复核连接、7 个持久包、所有瓦片和完整导出 ZIP；新提取请求失败且不增加完成包。浏览器端禁止远端请求后，OSM 地图与道路属性仍正常。

证据摘要见 [PMTiles 验收记录](../prototype/qa/pmtiles-verification.json)，独立核对脚本为 `scripts/verify-pmtiles-public.py`。自动化浏览器验收没有操作用户桌面，也不代表安装版 WebView 人工验收。
