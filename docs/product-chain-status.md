# Product-chain status — 2026-10-09

The public-data acquisition and local-result chain has a real completed example. The full distribution/account/commercial lifecycle has not finished acceptance. This release is an evaluation prerelease.

| Stage | Current evidence | Remaining boundary |
| --- | --- | --- |
| Product discovery | Live multilingual website, source atlas, GitHub link and real demo | Planned sources must remain clearly labeled |
| Acquire and launch | Reproducible Windows package/release workflow with source and hashes | Tag needs successful CI/publication; fresh-machine installation and startup are independent acceptance |
| Global account | Deployed email/Google/GitHub server, native PKCE/loopback/vault, protocol/UI tests | Real delivery, human consent and restored sessions need human acceptance for each provider |
| Model connection | Secure registry, real probes, streaming Agent and isolated histories | BYOK availability/cost and tool support vary; no hosted credit service |
| Request resolution | Global boundaries, district refinement, option cards, polygon defaults and coverage checks | Coverage/quality vary; ambiguities can require user decisions |
| Preview and approval | Right-side multiscene map and complete task cards | Preview does not download; model wording cannot grant authorization |
| Download/process | Real Manhattan Sentinel-2 original download/crop succeeded; same new result opened and goal verified | One flow does not prove all sources; protected originals and planned adapters keep release gates |
| Inspect/retain | Local GeoTIFF, metadata, source pixels, job history and file checks | No cloud sync; scientific/low-cloud usability depends on actual data |
| Update/notify | Signature verification, signed clients and activity gates tested | Production signing/channel and real upgrade/rollback acceptance unfinished |
| Commercial lifecycle | Independent positioning and public evaluation | Checkout, subscriptions/quotas and hosted-model billing are not implemented |

Directory: 85 entries / 16 groups; 31 available, 6 authorization required, 48 planned. These include products, protocols and local formats. Scope is 2D, including elevation rasters; 3D models/point clouds are excluded.

Real demo: Earth Search `S2A_18TWL_20261008_1_L2A`; New York County / Manhattan polygon; original download 325,522,286 bytes; crop 2,239,413 bytes, 1211 × 2253 at 10 m in EPSG:32618. These tasks predate packaging and are not installer acceptance. Copernicus Sentinel data (2026), via Earth Search.
