The subsequent development implementation adds conditional recovery for reviewed public STAC/direct-raster downloads. Before requesting asset bytes it revalidates the original source, provenance and selected layer; changed metadata or selection is rejected pending a new review. A checkpoint binds the task/source/asset, partial-prefix SHA-256, strong ETag and total size. Resume sends `Range` / `If-Range` and appends only an exact 206 response with the same strong ETag and valid `Content-Range` start/end/total. Missing strong validators, a changed HTTP representation, ignored Range, an incorrect partial response or 412 / 416 discards the old prefix and starts a fresh transfer; authorization refusal is not bypassed. Seven local TCP cases and the existing 12 recovery tests passed. This implementation does not change scientific samples, source entitlement, nighttime-light readiness or deployment status.
