# MODIS NDVI / EVI 联合质量筛选

2026-10-04。MOD13Q1 / MYD13Q1 v061 工程新增质量规则选择。处理重新读取每景的原始 NDVI、EVI、VI 质量标记和像元可靠性，按同一像元联合选景。较新合成周期不合格时，两种指数一起回退到较早合格的合成影像；没有合格候选时写入 NoData。验收记录见[质量筛选记录](../prototype/qa/modis-vi-quality-verification.json)。

这是 Planetary Computer 转换 COG 的能力，原文件接入见[两个指数](modis-vegetation-indices.md)和[辅助科学图层](modis-science-layers.md)。完整 NASA HDF 与受保护原文件不在本次验收中。

## 使用

在探索页选择 MODIS NDVI / EVI，创建工程或向当前工程追加影像。工程详情的“植被指数”工具栏选择 NDVI 或 EVI，以及“仅优质像元”“优质或边缘可用像元”或“保留原值”。质量处理要求每景的四份原文件完整下载；“下载指数及质量文件”只补充缺少的文件。

点击“质量筛选并裁剪”保存所选指数的 GeoTIFF。一个操作生成一个指数成果；在相同区域、同一组固定原文件及相同规则下分别生成 NDVI、EVI，两者使用相同的选景图。普通原值处理继续可用，按较新的非 NoData 值独立拼接，不自动筛掉质量标记。

文件详情、栅格检查和工作空间取值面板都显示使用的规则、全部输出像元统计与各景贡献量。来源详情提供每景四份原文件的链接和 SHA-256，并明确标注合成周期起始日期。下载、显示、处理与来源说明采用现有共用界面组件。

## 规则和科学含义

质量位定义来自 [NASA MOD13 v6.1 用户指南表 1 / 4 / 5](https://lpdaac.usgs.gov/documents/621/MOD13_User_Guide_V61.pdf)。下列阈值是 **GeoD 的产品规则**，不是 NASA 推荐的处理策略。

| 条件 | 仅优质像元 | 优质或边缘可用像元 |
|---|---|---|
| NDVI 和 EVI | 两者原 DN 都在 −2000 至 10000 范围内 | 同左 |
| MODLAND 质量两位 | 0 | 0 或 1 |
| 像元可靠性 | 0 | 0 或 1 |
| VI 可用性 | 0、1、2、4、8、9、10 | 同左 |
| 气溶胶 | 排除等级 3（高） | 同左 |
| 云 / 冰雪 / 阴影 | 排除邻近云、混合云、可能雪冰和可能阴影 | 同左 |
| 缺失与未定义 | 排除质量填充值、可靠性填充值 / 未定义等级和未定义可用性代码 | 同左 |

BRDF 与陆水类型保留其原含义，不当作品质排序分数。排序使用合成周期起始日期及产品 ID，**不按实际逐像元观测日序排序**。较新影像只缺少其中一个指数时，可以使用完整旧景，但不会将这种情况统计成“质量失败后回退”。

结果仍为 Int16 原始 DN，乘数 0.0001，NoData −3000，保留原 PixelIsArea 正弦网格；0 和负数指数不会被当成空值。标称 250 米与实际约 231.656358264 米像元间距分开记录。不平均、不重采样、不重投影。

统计含义：

- 完整指数候选：区域内至少一景的 NDVI / EVI 都在有效范围内的输出位置。
- 被质量筛选剔除：有完整指数候选但所有候选均未通过质量规则的位置。
- 保留较早合格观测：已有更新的完整指数候选，但最终保留较早合格候选的位置。
- 无合格观测：全部输出网格中的 NoData 位置，包括缺少完整指数、质量失败和多边形外部。
- 各景贡献量：最终取值来自该景的位置数；总和等于成果覆盖量。

这些是全分辨率统计，`countsFullResolution=true`。指数颜色预览中的有效采样数仍是预览采样，两种统计不会混用。

## 实际文件核对

复用此前通过原生下载验收的 Terra h08v05、Aqua h08v05 和相邻 Terra h09v05 共十二份完整原件、258,974,338 字节；本次新增下载数为零。独立 GDAL / Rasterio、NumPy、投影与几何工具读取 276,480,000 个原始 DN，核对五种范围、两种质量规则及两个指数共二十份成果的全部 **3,038,664 个 DN**、**1,698,248 个预览 / 缩略图 RGBA 像素**和 108 个成果原值点。

五种范围包括单景、跨日期重叠、带孔多边形、相邻瓦片和三景带孔范围。真实跨日期区域中，仅优质规则有 13,822 个像元因新景质量失败保留旧景，可用规则有 12,100 个；带孔范围分别为 9,901、6,462 个。相邻与三景范围没有出现质量回退，不以这些样本证明回退效果。每一对成果的选景摘要及 NDVI / EVI 全值摘要完全一致。

普通重启恢复三十二份原件 / 成果，缓存文件内容和身份保持不变。另在完全移除十二份父级原件、任务记录和工程记录的目录中，对二十份成果分别冷启动、重启、显示、取值和来源读取；二十张持久缓存不重新生成。损坏缓存可重建；改变成果文件或贡献量后，检查、缩略图和来源读取拒绝错误记录。原件损坏后处理失败、恢复后重试结果一致，取消任务不留下半成品。

直接和本地桥接两种只读 MCP 共核对 216 次成果原值读取，验证写入拒绝、断连拒绝与协议输出。生产界面在 1440 / 1024 / 900 像素、中英文和深浅主题中实际运行六个处理操作，输出等同于独立核对成果，地图真实点击与 GDAL 原值一致，折叠卡片高度和满高缩略图一致。原有六份未筛选指数成果在新运行时中再次核对，字节与历史验收相同。
