# 本地原始波段真彩色组合

2026-10-03。Landsat 8/9 Collection 2 L2 与 NASA HLS L30 v2.0 的同一景红、绿、蓝三个原始波段以及 MODIS MOD/MYD09A1 v061 的同一时段红、绿、蓝 COG 下载完成后，可从文件卡片的图层图标打开本地 RGB。工作空间选择器同时保留三个单波段入口，便于灰度检查。组合直接读取托管原文件，不请求在线 RGB 合成服务。

## 来源与网格校验

原生请求只接受三个已保存的任务 ID，固定顺序为 red、green、blue。任务必须为已完成的原文件下载，且属于相同产品、场景和原始产品目录。Landsat 处理日期不同的目录不能混用。逐个校验托管路径、文件字节数、完整 SHA-256、16 位采样类型、NoData、GeoTIFF 投影与产品网格（Landsat / HLS 为 30 米 UTM，MODIS 为约 463.31 米正弦投影）。

三个波段的宽高、CRS、外边界、像元间距与 PixelIsArea / PixelIsPoint 必须完全相同。不做隐式重投影或重采样。同一工程的三个派生单波段成果也可组合，但必须匹配完整来源场景顺序、区域、多边形、校准和网格；不能只按名称或尺寸匹配。VIIRS 准备层绑定同一原始 HDF5。

Landsat 为 UInt16，反射率使用 `DN × 0.0000275 − 0.2`；HLS 为 Int16，使用 `DN × 0.0001`。MODIS COG 为 Int16，使用 `DN × 0.0001`、NoData −28672，独立验收见[MODIS](modis-inspection.md)。Landsat / HLS 的 NoData 分别为 0 和 −9999；HLS 的有效 0、负值、以及超过 1 的反射率保持原值。[USGS Collection 2](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-reflectance)、[HLS L30](https://hls.gsfc.nasa.gov/products-description/l30/)

## 显示与科学取值

原生组件在三个原始网格上使用同一组最近邻采样位置，生成最大边长 768 的 RGBA PNG。任一通道为 NoData 的像元透明；三个通道共同有效的采样位置用于计算各自的 2–98 百分位显示范围。有效但范围恒定的通道显示为 128。没有共同有效样本时显示完全透明。

PNG 是本地显示预览，不能当成原始 RGB 数据文件。组合层不伪造文件路径、下载任务或合成文件 SHA-256；图层详情展示三个实际源任务与各自校验值。点击地图重新校验三个原文件，并返回全分辨率原始 DN、逐通道 NoData 和未经裁切的反射率，不从预览颜色反推科学值。

没有应用云、阴影、饱和或质量掩膜。原文件保留不变；同一时段的原始波段和匹配的工程成果均可组成 RGB，并可生成持久化[科学三波段 GeoTIFF](scientific-rgb.md)。MODIS 单波段支持[工程拼接与裁剪](modis-processing.md)。任意波段搭配和质量掩膜仍待接入。

读取受共享栅格并发许可、55 秒原生处理时限、60 秒客户端等待时限约束。每次只保留一个原始文件的已校验快照，加上三个有界采样数组；中断客户端等待不会释放仍在处理的原生许可。虚拟组合本身不伪造科学文件，源文件卡片继续使用已有持久化缩略图缓存。显式生成的科学 RGB 文件拥有独立文件校验值、缩略图、来源记录和交付包；移走父文件后仍可读取成果。

## 当前验证

[机器记录](../prototype/qa/local-rgb-verification.json)使用此前实际下载的同一 Landsat 9 场景三份完整 COG，重新校验约 281 MB 原文件。GDAL / Rasterio 独立核对网格、8 个位置的 24 个原始 DN 与反射率；NumPy / Pillow 重算全部 580,608 个 RGBA 预览像元及 1,741,824 个 RGB 通道值。

有符号 HLS 的负值、有效零、−9999、超过 1 的反射率、通道交集、不同网格、错误波段顺序、不同处理目录及篡改校验值使用明确的合成 GeoTIFF 单元测试。软件入口在明暗主题及 1440 / 1024 视口连接真实隔离 Rust API 验证；没有操作用户桌面。

NASA 没有测试账号，本记录不代表真实 Earthdata 正向授权或生产 HLS 原文件验收。软件内授权入口已实现，生产下载验证保持待验收状态。
