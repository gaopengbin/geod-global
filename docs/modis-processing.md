# MODIS 原始波段工程拼接与裁剪

2026-10-03。MOD09A1 / MYD09A1 Collection 6.1 的红、绿、蓝 COG 下载后，可在工程页分别执行「裁剪到工程区域」或「拼接并裁剪」。每个波段生成一份真实单波段 GeoTIFF，沿用已下载文件；成果支持本地地图、原始 DN / 反射率检查、持久化缩略图及重启恢复。

## 网格与科学值

输入必须属于相同的受支持产品和波段，且符合 MODLAND 原始 2400 × 2400 瓦片身份、正弦投影和对齐网格。处理前核对托管路径、完整 SHA-256、采样类型、NoData 和空间标签。半像元偏移、错误瓦片范围、不同波段或已改变的源文件会被拒绝。

输出保留 **Int16、NoData −28672、scale 0.0001、offset 0**，有效零、负数以及大于 1 的反射率不截断。采用 NASA MODLAND 参考球半径 6371007.181 米的正弦投影，中央经线、假东和假北为 0；PixelIsArea，实际像元间距约 463.312716528 米。应用使用固定标识 `MODIS:Sinusoidal`，不伪造 EPSG 编号。[NASA 网格参数](https://modis-land.gsfc.nasa.gov/GCTP.html)

WGS84 工程矩形转为正弦投影的包围窗口，并向外对齐完整源像元。包围计算包含赤道处的内部极值，不能只转换四个角。**矩形输出是源网格包围窗口**，没有精确经纬度边界掩膜。工程包含多边形时，按每个源像元中心转换回 WGS84，判断外环和孔洞，边界外设为 NoData；不执行栅格重投影或重采样。

输入按合成起始时间、再按产品 ID 排序；后面的有效 DN 覆盖先前值，后面的 NoData 保留先前有效值。相同时段也采用这个确定顺序，不代表逐像元观测日期或质量优先级。当前没有 QA、云、阴影或饱和掩膜。

成果按最多 512 行的条带写入 Deflate GeoTIFF，像元、掩膜及压缩缓冲遵守共享 64 MiB 条带预算。写完后完整解码回读并核对原始像元字节、空间元数据及 SHA-256；取消或校验失败不提交成功成果。单个源文件上限 512 MiB，16 位成果读取单边上限 20000 像元；较大区域需要拆分。结果不是 COG，运行应用无需外部 GDAL 或 Python。

文件包含可由 GDAL 直接识别的正弦投影 GeoTIFF 1.1 标签、NoData 和 scale / offset。来源清单记录完整无签名 COG 路径、源任务、产品 ID、源 SHA-256、各自合成时段、工程区域及输出校准参数，注明 Planetary Computer 转换 COG，不冒充 NASA 原始 HDF。[GeoTIFF 标准](https://docs.ogc.org/is/19-008r4/19-008r4.html)、[数据引用与政策](https://lpdaac.usgs.gov/data/data-citation-and-policies/)
