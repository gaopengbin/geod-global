# GeoD Global 0.2.5

## 中文

- 修复 MODIS 与 NDVI/EVI 预览：读取已校验的原始 COG，保留原始网格、数值和 NoData。
- 修复年末 MODIS 合成期检索误拒；单条不符合支持契约的目录记录不再丢弃其余有效结果，并明确提示排除数量。
- 无已接入文件覆盖的区域显示空结果和可用区域选择，不再误报连接失败或自动替换区域。
- 修复部分正常本地 GeoTIFF 导入被累计解码预算误挡，保留单块内存、文件大小与时限保护。
- 明确下载排队、连接、传输和校验状态；连接测试实际读取少量文件数据，缩小 NAIP 列表缩略图。
- 补正模型测试和部分连接失败的诊断统计；更新检查遇到短暂网络故障后有限重试。

工程、模型设置、账号与已下载文件保留。新版本下载和安装仍需用户确认。支持增量更新的旧版本在缓存和校验匹配时优先使用补丁，否则回退到完整签名安装包。0.2.0 需要先手动安装一次以启用可信更新。

## English

- Restore MODIS and NDVI/EVI previews from verified original COGs, retaining the original grid, DN and NoData.
- Accept exact publisher-declared year-end composite intervals. Invalid individual catalog records no longer discard verified neighbors; exclusions are disclosed.
- Treat unsupported coverage as an empty result with an explicit available-area choice, without silently changing the requested area.
- Fix valid local TIFF imports rejected by the cumulative decoding budget while retaining memory, file and time limits.
- Clarify queue, connection, transfer and validation states; read actual bounded bytes in connection tests and reduce NAIP list thumbnails.
- Correct failed model/partial-source diagnostics and retry transient update-check failures within a finite budget.

Existing projects, accounts, model settings and downloaded files are retained. Downloads and installation still require confirmation. Compatible previous versions prefer a verified delta when the cached base matches, falling back to the complete signed installer otherwise. Version 0.2.0 requires one manual bootstrap installation.
