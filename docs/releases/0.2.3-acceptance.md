# 0.2.3 release verification — 2026-10-26

The published payload was built once from clean source commit `e972b41a9099c1bf6d93b33c54c1434708ed2047`, now on the main branch and tagged `v0.2.3`. This acceptance document and the README labels are a documentation-only follow-up; they do not replace or rebuild the accepted binaries.

- [Cross-platform checks](https://github.com/gaopengbin/geod-global/actions/runs/40290965830): all checks passed on Windows 2025 and Ubuntu 24.04. Local frontend, Agent, runtime, desktop, packaging and release checks also passed.
- [Published release](https://github.com/gaopengbin/geod-global/releases/tag/v0.2.3): seven assets, each matching the accepted local size and SHA-256. The public release, tag and asset digests were read back without authentication.
- [CDN download](https://geod-global.laogao.xyz/zh/index.html#download): installer, ZIP, patch, signature, manifest and checksum files were fully downloaded and their exact bytes verified.

## Windows installation and signed updates

Actual Windows host acceptance used isolated installation and updater-cache directories. Existing uninstall registration, shortcut and updater cache were restored afterward. All 12,959 pre-existing application-data files retained their before/after SHA-256 values.

| Scenario | Result |
| --- | --- |
| 0.2.1 to 0.2.3, complete installer | Installed successfully; all 1,424 packaged files matched the manifest; an additional user-owned file was retained |
| Missing delta base | Downloaded and verified the complete signed installer |
| Deliberately corrupted delta | Rejected the patch and downloaded the complete signed installer |
| Real 0.2.1 to 0.2.3 delta | Reconstructed the accepted installer, verified its version-bound signature and installed successfully |
| Public HTTPS update feed, current-version comparison set to 0.2.2 | Production Rust updater SDK detected 0.2.3, downloaded the complete CDN installer and verified the signature; no installation requested in this additional check |

The complete installer is 310,829,607 bytes; its SHA-256 is `5d3d47eb407a97ebd79882f68ac830cbfae811bbbf6df9c1186d27de30a254d5`. The 212,208,534-byte patch saves 31.73%, reconstructs that exact installer, and is only offered for a matching 0.2.1 base. An installation without a matching base uses the complete package.

These are actual Windows 11 host installer and SDK tests. They are not a new clean-OS acceptance or a claim that every older client UI was manually exercised. 0.2.0 still requires one manual installation to bootstrap the trusted update channel. Windows Authenticode remains unsigned; the independent updater signature is verified separately.

## Packaged runtime and real files

The packaged runtime downloaded a new 95,194,940-byte Landsat red-band file through a TLS-preserving test proxy. One connection was deliberately interrupted after 5 MiB. It resumed from 5,193,728 bytes, recorded one network retry, and passed complete-file validation and independent SHA-256 readback. The test used a new job and a new observed interruption, not an existing completed receipt.

The same packaged runtime reopened previous isolated QA results. The production UI source at the same clean commit rendered Landsat RGB, a clipped Changping DEM and Sentinel-2 SCL. Independent raster reads matched displayed original values: RGB `9052 / 9345 / 8231`, elevation `66.05231475830078`, and SCL `4`. This checks those files and source values, not general positional or scientific accuracy for every provider. See the [repair investigation](../operations/download-preview-reliability-20261026.md) for transient preview failures and its evidence limits.

## Website and preservation

The website and trusted feed were switched atomically after the accepted CDN bytes passed verification. A subsequent public check verified 83 changed or protected files. All eight elevation/boundary case assets were preserved. Static checks retained 48 indexable public pages and 24 private pages with noindex; robots, sitemap and the server startup SEO gate were unchanged. The Chinese download and elevation-case pages were inspected at 1440 px and 390 px; the new download links were correct and no horizontal overflow was found.

No production database migration, new signing key, provider credentials, or new promotional post was part of this release.
