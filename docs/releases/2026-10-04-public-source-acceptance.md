- 分辨率矩阵的汇总只有在三份原件、五份结果、八组界面、五次处理、两种完整 MCP 会话与八张缓存全部通过后才标为通过。已经完成的 1 米隔离副本证据继续单独保留。
- 雷达验收等待文件列表加载后正常点击处理按钮，按大文件校验时间等待任务完成；实际检查点可恢复已完成界面和已提交任务。汇总按处理类型及极化分别绑定证据，避免相同字节的单景 / 拼接被当成同一项通过。
- 雷达报告保存按 SHA-256 定位的完整证据快照；新完成的原件单独登记，不覆盖已通过的处理和界面记录。错误快照绑定由私有报告控制拒绝。
- HV 失败后原任务续传，实际保存前缀哈希及跨恢复起点的 65,536 字节经独立条件 Range 核对。传输期间的这份证据保持部分状态；最终完整原件现已通过单独的长度、哈希与科学取值核对，不将独立请求当成捕获了 worker 的请求流量。

- 科学 RGB 的 Windows CLI 在直接目录和本地服务路径中可能栈溢出。启动入口将异步运行状态放到堆上，并由运行时工作线程执行；实际子进程回归和完整 CLI / MCP / HTTP 文件验收通过。
