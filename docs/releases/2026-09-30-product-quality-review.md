# 产品质量整改与发布门禁 · 2026-09-30

**结论：当前产品仍不满足最终交付和公开发布标准。** 打包成功、进程启动和自动化测试通过，不代表外观、可用性、功能覆盖与桌面操作已经验收。本轮是整改进展，不能作为“产品做完了”的依据。

开发与发行只使用独立仓库 `geod-global`。交付目标为 Windows 桌面版，经官网 / GitHub 下载；浏览器入口用于共享界面的开发检查。现有旧安装包不包含本轮修改。

## 本轮已落地的修复

| 问题 | 改动与可核验结果 |
| --- | --- |
| 工程、文件和任务的职责不清 | 工程卡片显示实际文件预览、文件数量和执行状态；工程详情区分源文件 / 处理结果；任务默认显示进行中，另外保留失败或中断任务及历史。 |
| 信息与动作分散、技术信息占据主界面 | 原始下载文件先显示采集日期与网格编号、类型和大小；来源、原始编号、校验值与高级操作收进详情。修改工程名紧邻名称。保留自定义成果名称。 |
| 打开文件只跳到空工作空间 | 统一保存路由中的文件、工程和文件视图参数。文件可以打开指定本地栅格；同一文件被多个工程复用时，工作空间保留打开它的工程，刷新后也能返回该工程。 |
| 真彩色下载后无法在本地工作空间读取 | RGB 和 SCL 都可加载本地文件并查询原始像元。RGB 显示三个通道，SCL 才显示分类色带；数据类型不混用。 |
| 工程处理按钮状态不明确 | 分别显示真彩色 / SCL 源文件就绪数量和进度；缺失文件、下载中、跨 UTM 网格等条件阻止不可执行操作。 |
| 加载和服务断开容易误导 | 缩略图断线后停止加载动画，重新连接可恢复；首次读取与离线状态不再显示“无任务 / 无文件”的假结论。 |
| 地图空间被工具面板占用 | 图层面板可收起；工具栏统一尺寸。RGB 单独绘制矩形裁剪尚未接入，不显示该按钮，已有工程裁剪从所属工程进入。 |
| 连续读像元时立刻报繁忙 | 保留单读取工作线程，在最多 5 秒的等待后执行下一次查询。请求结束不会提前释放正在工作的线程占用。 |
| 黑色真彩色像元被当作空白 | 预览以文件的 NoData 元数据决定透明度；没有 NoData 标记的黑色 RGB 像元保持不透明。 |

界面继续使用同一 Beautiful UI 适配层、蓝色主题和统一控件。辅助文字最小 12px；分类栅格的真实类别颜色不属于界面主题色。

## 本轮证据与边界

- `npm run verify`：仓库隔离、文档链接、契约、63 项客户端测试、25 项 UI 测试及生产构建通过。
- `cargo test --locked -p geod-runtime`：80 项测试通过；桌面 4 项测试在整体验证中通过。新增验证覆盖 RGB 元数据 / 像元、校验值改变、NoData 和读取线程等待。
- `cargo clippy --locked --workspace --all-targets --features geod-global-desktop/custom-protocol -- -D warnings`：通过。
- `npm run desktop:build`：生成包含本轮共享界面与 Rust 核心的本地调试可执行文件。没有生成新的公开发行安装包。
- 读取两份已有的真实 Sentinel-2 RGB 下载文件，分别来自 EPSG:32610 和 EPSG:32650，都是 10980 × 10980、10m。Rasterio 独立核对原始空间元数据、SHA-256 和 6 个像元的三个通道值，全部一致。未进行新的网络下载，也未修改原始文件。
- 浏览器实操确认：打开指定 RGB 文件、读取原始中心像元、返回所属工程；验证共享源文件在刷新后保留正确工程；查看真实工程预览、文件过滤和任务状态。检查中 / 英文、浅色 / 暗色及 1366×860、900×680 窗口，所检查页面没有横向溢出，可见文字不小于 12px。英文单复数等全局文案一致性还需继续审查。
- 证据保存在 `.verification/acceptance/2026-09-30-product-rgb-inspection.json` 与 `.verification/acceptance/ui-product-20260930/`。截图对应共享界面，**不是原生桌面窗口或托盘操作的验收证据**。
- 文件缩略图当前具有前端会话内缓存与重复请求合并；不把它描述为已实现的跨重启磁盘缓存。冷启动预览的耗时仍需测试。

## 仍阻止最终发布的问题

| 优先级 | 工作项 | 完成标准 |
| --- | --- | --- |
| P0 | 桌面完整主流程 | 在实际桌面窗口中走完选区 → 条件检索 → 多景选择 → 下载到同一工程 → 继续追加选景 → 查看进度 → RGB / SCL 拼接裁剪 → 查看结果 → 导出。不能以浏览器和 CLI 检查替代。 |
| P0 | 后台与恢复 | 在下载 / 处理时关闭窗口，实测托盘继续运行、恢复窗口、任务页、明确退出、再次启动和失败重试；确认没有丢失工程与文件。当前有生命周期自动化证据，原生交互仍未验收。 |
| P0 | 处理能力与数据源覆盖 | 补齐原规格要求的数据源和工作流；每项保留真实查询、下载和文件读取证据。当前可核验的处理主线仍是 Sentinel-2 SCL / UInt8 RGB、同网格 WGS84 UTM；不能声称全数据源、通用多波段或重投影已经完成。 |
| P0 | 文件和工程的生命周期 | 明确导入、移动、重命名、移除、保存位置与导出行为；实测原始文件缺失 / 校验改变 / 磁盘空间不足 / 中断写入时的可恢复反馈。未提供的操作不添加占位入口。 |
| P1 | 全页面视觉和可用性 | 探索、工程、文件、任务、设置、下载和处理弹窗，在两种语言、两种主题、最小桌面尺寸及 Windows 缩放下逐项验收。包括键盘操作、焦点、对齐、文字截断、动效、加载 / 空 / 错误状态。用户审阅通过后才关闭。 |
| P1 | 性能与稳定性 | 记录大范围、多日期、多景 COG 和本地文件的实际加载时间、内存和交互响应；检验冷启动缩略图、快速切换、网络断开、代理、取消和重试。当前构建仍有主入口大于 500KB 的分包提示。 |
| P1 | 发行与支持 | 新 Windows 环境安装 / 启动、支持的版本升级、卸载保留数据；明确签名或未签名发行策略、公开版本、干净提交与标签；官网说明、帮助、隐私、校验值及支持方式与实际能力一致。 |

完整终态不因本轮排序而缩减。此前记录的真实拼接、安装器和进程测试继续保留，但只证明相应版本与对应步骤；见[桌面候选记录](2026-09-30-desktop-candidate.md)和[完整发布门禁](../../GeoD-Global-Spec/06-Decisions-Contracts-and-Release-Gates.md)。
