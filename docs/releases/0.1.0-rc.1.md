# GeoD Global 0.1.0-rc.1

本阶段收敛为 Windows 10 / 11 x64 桌面发布候选，供试用和反馈。
不再为本候选扩大数据格式或平台范围。完整产品规划保留，后续接入另行推进。
发布资产以 [GitHub Release](https://github.com/gaopengbin/geod-global/releases/tag/v0.1.0-rc.1)
实际状态为准。候选发布不表示签名、干净设备和全部原生窗口验收已通过。

## 候选版包含什么

| 使用场景 | 本候选的范围 |
| --- | --- |
| 查找与下载 | 已验收的公开 Earth Search / Planetary Computer 等目录、区域和日期筛选、地图预览、可命名的多景工程、源文件任务与重试 |
| 使用本地栅格 | 真彩色、SCL、Landsat / MODIS 科学波段与质量层、NAIP、Copernicus DEM 和 Sentinel-1 RTC 的已验收文件读取、持久缩略图、地图和原值检查 |
| 工程处理 | 支持类型和兼容网格的裁剪 / 拼接，科学 RGB 及已明确验证的质量筛选；成果保留原始值和来源，可导出交付包 |
| 其他已接入数据 | 有界公开地图影像、矢量来源与本地文件、矢量 PMTiles / MBTiles 及显式三维演示资产；各入口的支持范围分别记录在随包说明中 |
| 桌面使用 | GeoD 品牌图标、单层自定义顶部栏、统一组件与蓝色主题、中英文、可调面板宽度、关闭到托盘、退出时停止任务 |
| 本地集成 | 独立 CLI 与 MCP，默认读取 / 预检，写入需显式启用；无远程自动上传 |

验收范围以 [数据源状态](../provider-integration-status.md) 和各类型说明为准。
公开目录、浏览图、渲染瓦片、转换后的 COG 和供应商原始产品是不同对象，
软件不因能显示预览就宣称能交付原产品。第三方数据的使用条件仍由该来源规定。

## 账号授权

“设置 → 数据源账号”已提供 NASA Earthdata 和 Copernicus 授权入口，
凭据保存使用 Windows 凭据管理器，密码及两步验证码不持久保存。
当前没有用于正向验收的测试账号，HLS、SRTM、VIIRS 和 Copernicus SAFE 原文件下载
在候选版界面中暂不开放。公开目录和账号设置保留。
协议与合成文件测试不能替代真实账号和生产原包验收。

## 明确的限制

- 工程处理需要受支持的类型、坐标系及网格；通用重投影、任意科学数据处理不在本候选范围。
- 地图服务保存的是渲染影像；区域查询有各入口独立的数量、尺寸和格式限制。
- 离线瓦片支持已验收的矢量 PMTiles 和矢量 / PNG / JPEG MBTiles；栅格 PMTiles 本轮不交付。
- 三维入口以有界显式文件及演示资产为验收对象，不代表商业供应商授权、点云或几何裁剪完成。
- 暂未提供 Authenticode 签名、自动更新或商店分发。安装前需要 WebView2 Runtime。
- 本候选的无桌面占用检查验证共享生产界面、原生核心及安装过程；
  不能据此宣称当前二进制的原生 WebView 窗口、系统托盘或干净设备上的人工体验已经验收。

## 安装和试用

使用安装程序或完整解压便携 ZIP，再运行 `geod-global-desktop.exe`。
关闭窗口后任务继续运行；升级前在托盘菜单选择“退出”。
卸载保留用户数据，便携包也不改变应用数据目录。
具体步骤见随包 `README.md`。

构建清单记录版本、源码提交、文件 SHA-256 和签名状态；
安装包、ZIP 的校验文件为 `SHA256SUMS.txt`。
包内保留第三方许可及必要源码档案，第一方仍为专有软件，见 `FIRST-PARTY-NOTICE.txt`。
本地检查报告单独记录实际结果，不将计划中的检查写成已完成。
