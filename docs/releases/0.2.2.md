# GeoD Global 0.2.2

- Add bounded, public acquisition labels for the Landsat tutorial's Zhihu and Bilibili distribution packages. Labels distinguish new and existing anonymous installations, remain separate from manual/Agent workflow channels, and accompany real search, download and artifact events.
- Retain collection/sharing opt-outs, GPC/DNT, event allowlists and the existing data retention policy. No account, referrer URL, file path, scene ID or precise location is added to telemetry.
- Include a reproducible Landsat 8/9 batch-download case with independently decoded and hashed original GeoTIFF files. The case downloads complete red/green/blue source bands; it does not crop or cloud-mask the imagery.

Channel packages contain the same application payload plus an `acquisition.json` public label. Removing that file does not affect searches, downloads or results. Installation IDs are not people, website visitor IDs are separate, and download clicks are not completed installations.
