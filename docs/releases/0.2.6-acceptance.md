# 0.2.6 release acceptance — 2026-11-06

The accepted packages were built once from clean commit `ba376ada7e2cfc354c8634cb6d5584671fd2326b`. All 22 Windows/Ubuntu head checks passed before publication. [PR #7](https://github.com/gaopengbin/geod-global/pull/7) is merged; the release tag identifies the exact package source. ## Included fixes

The release fixes the missing reviewed MODIS original-data origin in desktop CSP, explicit policy-versus-network diagnostics, bounded conditional-range recovery for Sentinel-1 polarizations, and original-download cache lookup incorrectly accepting a derived crop. It adds paired GeoTIFF/provenance JSON export. See the [release notes](0.2.6.md), [workflow investigation](../operations/user-workflow-reliability-20261106.md) and [provenance contract](../raster-provenance.md).

## Public delivery and limits

The [formal release](https://github.com/gaopengbin/geod-global/releases/tag/v0.2.6) uses eight immutable objects: installer, portable ZIP, checksums, artifact metadata, updater manifest/signature and two deltas. Every CDN object was downloaded in full and independently SHA-256 checked. Website byte verification covered 83 changed/protected files. The atomic website/feed deployment retained existing case assets, robots, sitemap and startup SEO gate; static validation reports 48 public indexable pages and 24 private noindex pages.

The release decision uses the real background installer, updater, runtime and public-delivery checks. Physical update-popup/install/relaunch, independent native Save-dialog output-location verification and new website screenshots were interrupted and remain **not completed**. They are not represented as passed or substituted with simulated UI results. Paired export and update installation were independently exercised through their actual native backend paths.

These are tests on the existing Windows host, not new clean-OS acceptance. Windows Authenticode remains unsigned; updater signatures are a separate verified mechanism. Version 0.2.0 still requires one manual installation to bootstrap trusted updates. No production database migration or new credentials were part of this release.

Detailed local receipts are under `.verification/release-026/`; immutable release source remains the accepted commit above.
