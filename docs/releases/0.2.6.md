# GeoD Global 0.2.6

## 修复与新增

- 修复桌面安全策略漏掉 MODIS 原件域名，导致 NDVI、EVI 和 MODIS RGB 预览在发出 HTTP 请求前失败的问题。预览、目录和匿名访问请求能区分安全策略拦截与网络故障。
- 为 Sentinel-1 VV/VH/HH/HV 原件启用有限的自动传输恢复。已有下载内容仅在校验值、ETag 和 Range 条件匹配时续接；取消和权限错误不会盲目重试。
- 修复项目再次请求原件时，可能复用同来源地址裁剪结果的问题。原件缓存仅复用下载任务，保留已有派生成果。
- 新增“保存栅格与来源记录”：成对保存 GeoTIFF 与同名来源 JSON，记录 STAC Item、原始资产、校验值和实际处理步骤。目录缺失会明确提示，支持有限重试；保留原网格时如实标记未重采样、未重投影。

现有工程、账号、模型设置和已下载文件继续保留。更新由用户确认后安装。增量包可用时优先使用；不满足条件时回退完整安装包，并验证完整包签名。

## Changes

- Permit the exact reviewed MODIS original-data origin in desktop policy; distinguish enforced browser-policy failures from network errors.
- Enable bounded conditional-range recovery for reviewed Sentinel-1 polarizations, retaining source validation, cancellation and permanent-error safeguards.
- Prevent original downloads from reusing derived crops with matching catalog URLs.
- Add paired GeoTIFF and portable provenance JSON export, retaining original STAC context where available, checksums and actual processing parameters. Missing context is explicit and retryable; no unperformed resampling or reprojection is claimed.

Existing projects, accounts, model settings and downloaded files are retained. Updates require user confirmation. Compatible delta packages are preferred, with signed full-installer fallback.

The application includes the existing separately signed Global updater channel. Windows Authenticode signing is not provided. See [raster provenance](../raster-provenance.md) and the dated [workflow verification](../operations/user-workflow-reliability-20261106.md) for behavior and evidence boundaries.
