# 0.2.0 release acceptance — October 19, 2026

The Windows x64 installer and portable archive use source commit
`a6f49e31545ca6f91c4097b8eebc85940e84f43d`. Later repository documentation and CI
tool-version fixes do not replace the accepted executable bytes.

| Check | Observed outcome |

| Actual funnel events | Receiver readback included search, preview, review, confirmation, submit, two download completions, two artifact validations and artifact opened |

The validation statement is file integrity, not independent scientific quality
assurance. The downloaded assets are 20 m SCL classification originals, not RGB
imagery, a cropped deliverable or a claim of cloud-free coverage. Their sources
are Copernicus Sentinel-2 L2A via Earth Search / Element 84.

This build was exercised on the Windows 11 x64 host with fresh WebView
preferences; existing native application data was retained. It is **not a new
clean-OS test**. The earlier rc.5 Windows 10 LTSC guest acceptance belongs to that
earlier candidate. No macOS/Linux/ARM installer acceptance is claimed.

The current executables are unsigned and require WebView2. No automatic signed
update is enabled. Source-specific authorization, quota and license restrictions
remain applicable. This task did not re-run every directory entry or a new
paid-model conversation.

Production-mode acceptance traffic is marked as QA in the private acceptance
receipts. These test installations and sessions must be excluded when reporting
real-user adoption; anonymous installation counts are not people counts.

The initial GitHub runner stopped before tests because its newer bundled npm
resolved optional lockfile packages differently. Repository CI now pins npm
11.6.2, matching the package manager used for this accepted build. The package
lock and application dependencies were not changed by that CI fix.

A subsequent replay-test failure was a report-text serialization issue: Git
stores LF while the three historical Windows JSON receipt hashes were frozen
with CRLF. The test now reconstructs that original line ending before checking
the unchanged receipt hashes. Original raster and preview byte checks remain
exact. This changes test portability, not application behavior or downloaded
data.
