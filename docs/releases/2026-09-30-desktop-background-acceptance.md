## 检查发现的路径错误

后台下载完成后，桌面缩略图与本地地图拒绝读取已校验的源文件，错误为
`Raster inspection is restricted to this job's managed asset file`。
实际文件解析到了 Windows 包上下文的 `LocalCache/Local` 位置，而父目录仍
解析为名义上的 AppData 位置。Windows 的文件合并视图允许这种情况，参见
[Microsoft 的应用数据虚拟化说明](https://learn.microsoft.com/en-us/windows/msix/desktop/flexible-virtualization)。

修复统一了读取、拼接输入、成果包及原生文件定位的路径校验：
先保留原有工程目录检查，再解析**指定任务文件与记录文件两端**的真实位置。
只接受普通文件，拒绝符号链接及 Windows reparse point，仍检查精确文件名、
任务标识、大小和 SHA-256；未改成任意目录或任意文件访问。
成果包返回实际解析路径，便于资源管理器准确定位。

没有使用概览或预览图代替源文件。为检查处理时隐藏窗口另生成了一份 RGB 成果，
但两次处理在关闭窗口前都已完成，不能算作处理中的后台运行验证；该额外成果保留在验收工程中。

随后在真实桌面工作空间打开 RGB 与 SCL 成果，确认地图显示成功、读取原始像元，
