# GeoD Global 0.2.3

## 下载与预览恢复

- 公开内置 COG 数据源下载遇到短暂断线时，最多自动恢复两次，并沿用已验证的断点；取消、权限错误、文件校验失败不会被自动重试。
- 地图预览保留真实的请求阶段、HTTP 状态和重试次数，慢请求可以在限时内恢复。兼容未暴露 Content-Range 响应头的公开存储。
- 保留 0.2.2 教程包的安装来源标记和渠道归因，普通正式版不预设推广渠道。
- 沿用独立签名的自动更新通道，下载和安装分别由用户确认。增量包仅在校验通过且明显小于完整安装包时提供；缺少基包或增量校验失败时回退完整安装包。

## Download and preview recovery

- Resume transient interruptions for reviewed built-in public COG downloads, with a maximum of two retries and verified checkpoints. Cancellation, permanent access errors and validation failures are not retried.
- Preserve preview request stages, HTTP statuses and retry counts, including bounded recovery of slow requests and public-storage CORS compatibility.
- Retain the acquisition attribution shipped in the 0.2.2 tutorial packages. The general release does not preselect a campaign.
- Keep signed, user-confirmed Windows updates, validated delta delivery when worthwhile, and full-package fallback.

Repair verification and its limits are documented in `docs/operations/download-preview-reliability-20261026.md`. Windows host installation and update acceptance is recorded separately with the exact published package hashes. This release does not claim a new clean Windows environment test.
