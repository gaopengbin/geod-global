# 探索页公开来源预览

2026-10-04。来源菜单分别标注原文件可用性和地图预览方式。九个已开放原文件的入口中，五个自动预览，四个在选景并点击加载后读取原始 COG；NASA 与 Copernicus 的六个待账号验收入口继续标为“仅目录”，地图只显示范围。列表缩略图不代表地图已经加载，也不代表完整原产品已经下载。

| 来源 | 探索地图 | 显示含义 |
|---|---|---|
| MODIS NDVI / EVI | 自动在线预览，可切换指数 | 固定 −0.2 至 1.0 色带，NoData 透明 |
| Sentinel-1 RTC | 自动在线预览，可切换当前景具备的极化 | 原始线性 gamma0 显示为 −30 至 0 dB 灰度 |
| MODIS 8 天反射率 | 自动在线 RGB | 原始波段 1 / 4 / 3；反射率 0 至 0.3，gamma 2.2 |
| Copernicus DEM GLO-30 Public / GLO-90 | 自动读取当前公开原始高程 COG | EGM2008 米制高程按 −100 至 1000 米灰度显示 |
| NAIP | 选景后加载原始四通道 COG 的 RGB | 美国航空影像，近红外通道保留在原文件中 |
| Earth Search / Planetary Computer Sentinel-2 | 选景后加载原始真彩色 COG | 原有多景与同网格对比功能保持独立 |
| Planetary Computer Landsat | 选景后加载原始 B4 / B3 / B2 COG | 原始 DN 按固定反射率参数显示 |

在线 MODIS / 雷达使用供应商的条目级 PNG 瓦片 API，固定完整条目身份、波段、比例、NoData 和最近邻重投影参数；颜色只用于显示，不改变下载文件。植被与反射率没有质量掩膜，雷达没有散斑滤波或额外定标。雷达的有效零值按显示下限显示，只有原文件声明的 −32768 为 NoData；不能把零强度解释为有限的物理 dB。[官方接口参数](https://planetarycomputer.microsoft.com/api/data/v1/openapi.json)

地图显示实际影像时，影像范围仅画状态边线，保留透明填充用于区域命中；多景重叠不会把固定色带、灰度或真彩色染成范围色。尚未加载影像时继续以轻填充提示覆盖范围。

高程读取同一份 AWS 公开 COG。由于两个公开桶没有浏览器 CORS 响应，桌面使用私有 `geod-elevation` 通道，浏览器开发适配使用只读本地接口；原生层只接受已审核 GLO-30 / GLO-90 的具名瓦片和单个有限 Range，固定官方地址，拒绝任意 URL、重定向和完整文件响应。每次最多 4 MiB、四个并发请求，验证返回区间、长度和总文件上限，沿用用户的运行时代理设置；不登记下载任务或文件。

实际 TIFF 的 Float32、EPSG:4326、Point 语义、列数、像元间距和原点必须与当前瓦片一致。Point 的像元中心与外边界相差半像元，显示校正只改变几何，不改变高程。有效零高程保留，缺失值按实际 TIFF 声明处理；未设置统一的零值掩膜。私有通道已加入桌面开发和生产网络权限，未开放通用 URL 代理或任意存储桶。

初次在线预览以搜索区域为中心，再执行原有缩放动效，避免从大型 MODIS 整景中心横跨远距离并请求途中瓦片。临时网络、HTTP 408 / 425 / 429 / 5xx 错误最多请求三次，等待 250 / 750 毫秒；授权拒绝、异常内容和其他请求错误不会变成透明图。仅接口明确返回的“瓦片在条目范围外”404 才作为透明瓦片。切换来源、场景或显示通道会取消旧请求和等待；持续失败保留地图重试入口。

Planetary Computer 的临时访问签名申请也对网络中断和 5xx 最多请求三次，总时限 30 秒；签名接口的 429 保留明确限流提示和手动重试，不套用瓦片重试策略。访问令牌仍只保存在内存，不进入工程或来源记录。

## NAIP 历史目录兼容

实际旧条目 `ca_m_3712221_sw_10_.6_20160625_20161004` 对应官方原文件 `ca_060cm_2016/37122/m_3712221_sw_10_h_20160625.tif`。旧版只接受数字分辨率标记，导致包含这些合法条目的整页查询失败。现在 `h` 文件和 `.6` 目录身份按经核对的 0.6 米命名绑定，保留州、年份、网格、象限、UTM 区号、采集日期及完整目录 ID 检查，不接受任意别名。

该原始四通道文件将 NIR 标成 ExtraSamples=2。只有精确匹配的 `h` / `.6` 原文件与官方 red / green / blue / nir 声明、NAD83 UTM / 0.6 米 Area 网格一致时，才允许这项遗留标记；其他 alpha 文件继续拒绝。前端在线读取与原生下载 / 检查使用同样的身份范围。[十五条原始目录及实际头部记录](../prototype/qa/naip-legacy-catalog.json)

## 可重复验证

[本轮机器验收记录](../prototype/qa/public-catalog-preview-verification.json)保存九个公开入口、十四项实际地图 / 切换 / 重试检查、原始 Range 和 PNG 回执、截图与源码 / 构建哈希；535 项前端测试及原生桌面编译检查通过。实测区域为 `[-122.55, 37.68, -122.32, 37.84]`，一般目录日期为 2026-09-05 至 2026-10-04，NAIP 历史日期从 2010 年开始。

[实时浏览器验收](../scripts/verify-public-catalog-preview.mjs)使用当前生产界面、桌面 CSP 和隔离原生服务，逐一向九个公开来源查询并读取真实地图像素；同时检查指数、极化、平台切换、请求失败重试，以及中文深浅主题和较小窗口。它读取公开原文件的必要 Range，不创建下载任务、不保存凭据、不操作用户桌面。地图成功必须有实际影像 canvas 像素，不能仅凭缩略图或影像范围通过。

[独立像元检查](../scripts/verify-catalog-preview-pixels.py)复用以前接受且再次核对 SHA-256 的三份 MODIS RGB 原件和一份 Sentinel-1C VV 原件，独立转换瓦片像元中心坐标并比较最近邻原始值、显示拉伸与 gamma。83 个不在采样边界附近的样本通过，显示通道允许 1 个 8 位色阶的数值舍入差异；不把抽样说成整幅图像逐像元验收，也不重复计数为新原文件下载。依赖见[科学验收版本](../requirements-raster-qa.txt)。

本轮 NAIP 历史原件的文件身份、实际头部和在线 Range 显示，与先前各分辨率整文件处理验收分别记录；未将其宣称为新完成的整文件处理。无头生产界面验证也不代替原生 WebView、安装版或所有地区 / 年份的人工验收。各产品既有下载和处理证据保持独立，见[接入状态](provider-integration-status.md)。
