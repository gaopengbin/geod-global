## 高程数据接入约束

三个已接入的高程入口分别固定产品身份：GLO-30 Public 与 GLO-90 是不同分辨率的 Float32 / EGM2008，SRTMGL1 v003 是有符号 Int16 HGT / EGM96（EPSG:5773）。SRTM 的 3601 × 3601 网格共享边缘采样点，不能套用 GLO-30 的列数、垂直参考和文件类型。三个入口均不提供光学云量筛选或逐景日期时间轴，不能将 2000 年 SRTM 任务时间解释为逐瓦片采集时间。具体源约束与证据见[SRTM 说明](srtm-inspection.md)。

Copernicus DEM 两个入口分别采用 AWS 公开的 GLO-30 Public 与 GLO-90 COG 路径，不使用需要登录的 CDSE 原产品接口。官方公开桶支持匿名访问；公开版包含覆盖限制，海洋可能没有瓦片，不能以空返回判定服务故障。[AWS 数据说明](https://registry.opendata.aws/copernicus-dem/)

该产品是包含建筑和植被的 DSM。高程使用米、垂直参考 EGM2008（EPSG:3855）；水平网格是经纬度 EPSG:4326。地理像元间距以角度记录，不能把经纬度步长直接标成米。[Copernicus 产品规格](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)

本轮实际文件为 3600 × 3600、单波段 Float32，GeoTIFF 没有声明 NoData；包含有效的 0 和负数高程，不能套用 Landsat 的 DN=0 掩膜，也不能转成整数或使用反射率 scale/offset。实际文件、完整 SHA-256、原始目录响应与五个独立样本见[高程源预验证](../prototype/qa/dem-source-verification.json)。该记录保留接入前的外部预验证状态；应用内实现、真实原生下载和界面证据另见[高程读取验收](elevation-inspection.md)。

PixelIsPoint 采用半像元外边界，地图与取值必须一致。目录中的 2021 年时间不能渲染成每景观测日期；高程入口不提供光学影像的云量筛选和时间轴。高纬度 COG 的宽度与经度间距会改变，不能对所有瓦片硬编码 3600 列；以文件和目录元数据核对。[COG 处理说明](https://copernicus-dem-30m.s3.amazonaws.com/readme.html)

下载及派生结果需附带具体公开版、来源与许可 / 署名链接。显示用拉伸、伪彩色和概览层与原始 Float32 高程分开；科学取值返回原值。新类型接入需要同时覆盖工程恢复、持久化缩略图、地图、原值检查和实际输出核对。
