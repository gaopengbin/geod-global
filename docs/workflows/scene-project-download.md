# 从下载到影像工程

探索页加载影像后，在详情面板点击 **新建工程并下载**：

1. 输入工程名称，选择真彩色 GeoTIFF、SCL 分类栅格或两者。
2. 点击 **创建工程并开始下载**。工程先保存影像记录、源文件链接和所选区域，再加入本地下载队列。
3. 当前页显示工程已保存及下载状态。可以继续探索，或明确点击 **打开工程** 查看进度。
4. 工程页面只显示该工程的源文件和工程处理结果。下载完成后，可按工程区域裁剪单景，或分别对同一坐标网格的多景真彩色/SCL 进行拼接与裁剪。
5. 点击工程名称旁的编辑按钮可修改名称；刷新或重启后仍保留。**全部工程** 返回工程列表。

文件保存在本地工作空间，不会自动放入浏览器的下载文件夹。下载弹窗不展示系统存储路径；文件详情按需展示正常的本地路径，隐藏 Windows 内部的 `\\?\` 前缀。源文件不因下载而自动裁剪；处理结果是独立的 GeoTIFF。

若工程保存成功但加入队列失败，重试使用同一个工程。下载任务失败、取消或中断后，可在工程内明确重试。已完成的相同源文件会复用；多个工程可引用同一份源文件，但各自的工程裁剪/拼接结果通过工程 ID 区分。旧的孤立下载仍可从“我的数据”的全部文件列表访问。

每个工程最多 32 景。当前拼接要求相同 UTM 坐标系统、像元尺寸和网格，不执行重投影；SCL 与真彩色分别处理。源文件下载有 512 MiB 单文件上限。文件下载校验包括传输长度、格式签名和 SHA-256，不能替代科学数据质量检验。
