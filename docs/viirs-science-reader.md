# VIIRS v002 原文件内部读取校验

2026-10-02。在完整原文件下载适配之后，加入纯 Rust、只读的 HDF5
内部校验器。只接受 VNP09A1 / VJ109A1 / VJ209A1 v002，不能推广到其他
VIIRS 产品。**以下正向验证全部使用明确标注的合成文件，不是生产原文件验收。**

## 当前行为

下载完成、提交成功记录之前，用下载 SHA-256 核对不可变字节快照。
512 MiB 上限、原生栅格任务并发限制、取消、超时和失败清理继续生效。
不启用 HDF5 外部文件或外部链接解析器，不调用系统 GDAL、Python 或 HDF5 DLL。

从 `/HDFEOS/ADDITIONAL/FILE_ATTRIBUTES` 核对文件内产品 ID、ShortName、
v002、VIIRS 传感器、完整 UTC 合成时段和 h/v 瓦片。解析
`/HDFEOS INFORMATION/StructMetadata.0` 的唯一网格；拒绝重复键、错误轴序、
不完整结构、错误球体或与产品瓦片不符的边界。实际网格来自文件内元数据，
不以目录 WGS84 包围盒或“标称 1 千米”替代。

用网格名定位 M5/red、M4/green、M3/blue。每层必须是 1200 × 1200 Int16，
原值、填充值 -28672、有效范围 -100..16000、比例 0.0001、偏移 0 必须符合
[NASA v2 用户指南](https://lpdaac.usgs.gov/documents/1657/VNP09_User_Guide_V2.pdf)。
读取全部 4,320,000 个 DN，分别计算规范小端编码的 SHA-256、非填充值极值、
NoData 和有效范围之外的数量。有效范围之外的值仅统计，未改写或掩膜。

原 HDF5 文件保留全部字节，不生成伪真彩色文件。新任务保存与原文件 SHA-256
绑定的 `viirsScience` 摘要；重启后验证摘要身份、几何、定标和计数约束。
文件详情显示已核对的波段、网格和定标信息，明确未应用质量掩膜。
旧任务没有摘要时，仍显示原有传输检查边界，不补写未经验证的结果。
无法解码、缺失字段或不符合所支持结构的文件不会标为下载校验成功。

## 独立合成测试证据

[夹具说明](../crates/geod-runtime/fixtures/viirs/README.md)、
[h5py/NumPy 预期值](../crates/geod-runtime/fixtures/viirs/expected.json)和
[Rust 实际摘要](../prototype/qa/viirs-science-summary-fixtures.json)可交叉核对。
三份合成文件共有 12,960,000 个 DN，全部通过独立工具生成的哈希验证。
覆盖大/小端、早期/新版 HDF5 superblock、连续布局、不整除的分块、gzip、
shuffle、Fletcher32、有效负值、NoData 和一个未掩膜的超范围值。

七份独立异常夹具覆盖错误定标、错误版本、错误网格、UInt16 冒充 Int16、
超大维度、外部文件链接和损坏分块。其他回归覆盖 SHA-256 / 大小变更、取消、
产品混淆、截断与仅含 HDF5 文件头的无效文件。原生 HTTP 任务测试实际走
下载、读取、原子提交、失败清理和重启恢复，但请求对象是测试服务器上的
合成文件，**不证明 Earthdata 生产授权成功**。
