# 地理空间数据云接入 — 2026-10-15

本次接入了 GeoD Global 的公开目录、覆盖范围、官网原生登录，以及 **六类公开地形产品的完整 ZIP 原件下载**：SRTMDEM90m、坡度、坡位、ASTER GDEM V1/V2/V3。[新增五类产品的实际验收](gscloud-public-originals-20261015.md)另列。其他产品、预订与压缩包内栅格预览尚未接完，不能按整个平台全部可下载宣传。

## 已实现

- 探索页图源弹窗中选择“地理空间数据云”，进入现有侧栏与地图，不另开产品页面。
- 从当前官网 GeoAgent 接口读取产品树，按其实际分类选择产品；本次真实返回 124 个产品条目。这是目录数量，不代表 124 类原件均已验证。
- 选择区域后自动检索，可按产品、时间、云量和文件收录状态筛选；每页最多 20 条，分页浏览最多 200 条。
- 官网接口没有公开的稳定分页快照保证；分页去重后不足目录总数时，界面提示结果不完整，Agent 上下文不会标为完整。
- 使用紧凑列表多选，最多选择 20 条，分批读取详情并展示发布方真实 Polygon / MultiPolygon。缺失边界保持未知，不用中心点或矩形补造影像范围。
- “已收录”“需预订”“状态未知”单独展示。已收录并不等于账号有下载权，也不自动创建任务。
- Agent 提供 `geod_gscloud_products/search/detail`。探索页侧栏携带当前产品、区域和筛选条件；首页不继承该上下文。工具只读元数据，不接收登录凭据。
- 桌面版在独立、临时浏览窗口中打开官网原生登录页，支持官网邮箱登录与已列明的官方第三方登录跳转；不再由 GeoD 收集密码、验证码或复刻 RSA 登录请求。官网登录后返回软件点击“已完成登录，验证连接”，原生代码仅读取数据云本站会话，并向官网核验已登录账号菜单，验证成功后保存到按工作目录隔离的 Windows 凭据管理器。远程登录页没有桌面命令权限，浏览器预览没有账号写入接口。
- 重新打开后只显示“会话已保存、待验证”，不把本地存有会话当成仍然有效或可以下载。
- 选择 SRTMDEM90m（产品 305）后，可显式下载最多 4 份已收录原件。每份原生任务重新核查目录身份、实际分幅边界与文件状态；只访问官网当前公布的 HTTPS 下载通道，不接受客户端传入地址。
- 原件进入既有任务队列，可查看字节进度、取消、重新完整下载和打开文件夹。完整 ZIP 保持原样，校验分幅名称、ERDAS IMG 文件头、成员长度、ZIP CRC 和整个原件 SHA-256。暂不支持断点续传，重试不会拼接未知版本文件。
- 官网下载地址中的临时 `sid/uid` 仅在原生请求内使用，不写入任务、模型上下文、日志或前端。每次请求重新获取授权，不沿用已失效地址；不会自动提交预订或用途申请。
