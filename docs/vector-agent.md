# 矢量数据的 MCP / Agent 接入

2026-10-05。已接通六个只读工具，以及矢量提取审核、软件内修改与确认、原子结果登记和重启复用。复用现有桌面原生查询、原件校验和格式转换；模型只能生成审核方案，确认及提取由软件原生入口执行。本次是本机开发增量，没有发布新版。

## 已实现的工具

| 工具 | 实际行为 |
| --- | --- |
| `geod_feature_services` | 分页读取已保存的 OGC API Features、ArcGIS、WFS 2、Overpass 服务摘要 |
| `geod_feature_collections` | 读取实际服务 ID 对应的原始集合声明 |
| `geod_vectors_list` | 读取已登记矢量文件摘要，明确标注内容尚未校验 |
| `geod_vector_inspect` | 重新校验原文件、原生转换结果和来源记录，返回哈希及实际元数据 |
| `geod_vector_features` | 分页读取要素索引、身份、几何类型和哈希；遗漏的大字段提供读取引用 |
| `geod_vector_node` | 按要素索引和 JSON Pointer 读取属性及几何节点，保留原始键、数组位置和数值 |

服务和集合工具只读取保存的声明，不请求外部服务，不能证明该服务目前在线或仍允许下载。文件读取工具调用原有 `inspect_vector`，原件或转换结果发生变化时拒绝继续。二进制格式使用现有声明的原生转换；工具本身不额外简化几何、舍入坐标或重新投影。既有只读模型验收使用 GeoJSON，新增审核流程另验收了 WFS 的 GML 响应档案和 Overpass 原始 JSON；不能据此声称所有二进制格式都完成模型验收。

## 分页与数据完整性

原生记录页最多 100 项，条目正文限制为 24 KiB；Agent 每页最多 20 项，并继续使用已有 32 KiB 响应上限。实际一页可以更短，返回真实 `nextOffset`，不能把部分页面解释为全部结果。单个元数据条目超过边界时明确报错。

节点里的小值直接返回，大对象或数组给出后续节点引用，不截成伪完整值。对象按原始键、数组按原始索引分页；字符串每次最多 4096 个 Unicode 标量，用 `nextOffset` 继续，偏移上限覆盖原生文件的 20 MiB 大小边界。要素及节点均提供哈希，可与完整本地文件核对。

模型视图沿用已有凭据、路径和传输地址过滤。被过滤的数据显式标注 `redacted` / `valueOmitted`，不宣称模型视图完整；字符串在分块前检查整个原值，不能用偏移绕过过滤。原生 MCP 和本地原文件保持原值，原生生成的结构指针保留供后续读取。外部属性、集合说明和数据内容始终作为数据处理，不作为执行指令。

结果引用新增 `vector` 类型，只接受实际登记的文件 ID，打开现有工作空间矢量视图。矢量读取不会生成栅格任务、工程或计划，也不会显示虚假的下载完成状态。

## 先前只读工具的实际验收

独立测试目录内由原生验收程序连接公开 pygeoapi 的 `lakes` 集合，以边界框 `[-130,20,-60,65]`、每页 2 项提取七页真实数据，登记为一个本地 GeoJSON。**提取由验收程序完成，模型没有执行提取。** 查询返回完整相交要素，不隐式裁剪几何到边界框。

实际得到 13 个 Polygon 要素、253 个坐标位置、14,842 字节。原文件和原生 GeoJSON 的 SHA-256 均为：

```text
9fcb466a929fcc6f6a4ece0ad005349a150398ad0096c42a2ddbd8d16a183b6e
```

已有 `deepseek-v4-flash` 兼容中转路线完成两轮真实对话、十次成功工具调用，涵盖六个工具及属性 / 坐标节点读取。关闭后重新打开原生运行时和会话，第二轮重新校验文件并读取属性；文件、服务记录、任务、工程和计划数量没有被只读对话改变。这证明该已配置路线的工具往返，不证明其他模型或上游供应商身份。

独立脚本重新请求全部七页原始数据，属性和几何与保存文件逐项相同；GEOS 检查了几何有效性和查询边界相交。随后真实 MCP 的直接目录、回环服务两种连接分别完成 44 次调用，分页重建全部 13 个要素，结果与原件一致。阻断外部请求后读取仍成功，代理捕获的外部请求为零，原件及登记文件哈希保持不变。

原生单元测试另外覆盖大几何、转义属性键、长 Unicode 字符串、百万字符以上偏移、字节边界分页、敏感字符串分块过滤、同大小原件损坏、直接 / 回环读取一致及非法参数拒绝。界面检查使用明确标注的合成响应，覆盖语言、宽度、主题、矢量结果链接和 CSP；这不是原生窗口人工验收。

证据位于 `.verification/agent-vector-model-1791188665810393100/`，其中 `case/native-acceptance.json` 保存真实模型与重启记录，`vector-data-verification/acceptance.json` 保存独立原件、完整要素和离线 MCP 核对。`scripts/verify-agent-stac-model.py` 使用 `--scenario vector`，并以必需的 `--test-binary` 指定已编译的原生桌面测试程序，可在新的隔离目录重做真实模型验收；需要已有模型授权和仓库内准备好的 Agent 运行时。`scripts/verify-vector-agent-data.py` 使用必需的 `--case` 指定上述验收目录、`--executable` 指定本仓库编译的 `geod-runtime.exe`，继续做独立核对。脚本只清理自己创建的进程，不操作用户桌面。

## 已实现：矢量提取审核与结果登记

`geod_vector_extract_plan` 使用软件内已经保存的服务 ID 和集合 ID，固定连接完整元数据的 SHA-256、协议、集合声明、WGS84 范围 / 原生多边形、输出名、分页大小及 WFS 响应格式。生成方案不发送外部提取请求，也不创建矢量文件或栅格任务；服务当前是否在线、实际要素数与字节数保持未知。

审核卡提供范围与集合详情、修改入口和单独的“确认提取”。修改范围、名称或多边形选择会生成新哈希和新方案，旧卡不能执行。协议、服务和集合不能通过修改表单替换。确认必须来自已选会话中的实际审核卡，并匹配会话、方案 ID、哈希和有效期。连接或集合声明变化后拒绝旧方案，要求重新审核。

确认入口才调用现有协议适配器：OGC API Features / ArcGIS 返回完整相交要素；WFS 2 保留已声明的响应格式、原始响应档案及协议校验；Overpass 保留完整 OSM 依赖几何、原始响应及已有小区域限制。它们都不隐式裁剪几何。WFS 格式和 Overpass 面积限制另有明确标注的原生合成测试，四种协议也分别有公开样例的实际模型审核、确认和重启验收。

分页只用于 OGC / ArcGIS / WFS，默认每页 200 项；Overpass 必须省略 `pageSize`，审核与修改阶段即拒绝分页参数，界面中的对应值为 `null`。矢量提取是同步操作，不生成栅格任务；方案为 `submitted` 且真实文件 `verified=true` 时表示已经保存，模型另用新鲜的文件检查核对结果，不把空任务列表解释为未完成。

结果使用方案对应的确定矢量 ID。确认记录与实际 VectorAsset 一起原子写入矢量登记；登记失败时回滚新原件。文件已写好而登记前退出时，只有匹配方案的确认记录、范围 / 协议来源和原件 / 转换哈希全部通过，才能恢复登记。只读状态查询不把未登记文件升级为完成结果。重复确认、服务删除后的已确认结果、重启复用以及原件损坏拒绝均经过原生测试。

已登记结果卡显示实际数量、字节和校验状态，链接到现有工作空间。方案不借用栅格任务来显示矢量完成，也不新增第二套查询或转换业务逻辑。外部 MCP 的写工具数量和授权方式保持原有契约；新审核工具仅向桌面 Agent 开放。

## WFS / ArcGIS / Overpass 的实际模型验收

三组独立公开样例均完成三轮实际模型对话、13 次成功原生工具调用，以及修改方案、拒绝旧哈希、单独原生确认、同一会话与模型线程重启、重复确认复用一个文件。人工修改记录单独计数，不冒充模型工具调用。模型没有执行提取，隔离测试没有操作用户桌面或写入用户模型连接。

| 协议与样例 | 实际保存结果 | 独立核对 |
| --- | --- | --- |
| WFS 2，MapServer `ms:cities`，柏林范围 | 1 个 Point，1 个坐标位置，7,361 字节原始 GML 响应档案 | 独立 XML 解码、字段模式、轴顺序和前后两次原始响应核对；本地导出与原生转换哈希一致 |
| ArcGIS，Esri 公开地震样例 | 6 个 Point，6 个坐标位置，9,177 字节 GeoJSON | 重新请求三批完整 GeoJSON，再单独请求 Esri JSON；所有属性与坐标一致 |
| Overpass，柏林小范围建筑 | 7 个 Polygon、2 个 MultiPolygon，196 个坐标位置，54,941 字节原始 JSON | 原始对象、145 个依赖、标签、节点 / 成员引用与角色核对；独立 GEOS 几何相等，保留 3 个洞及范围外的完整几何 |

实际 MCP 的直接目录、回环服务分别完整重建每组全部要素，调用数依次为 6 / 13 / 32。读取时阻断外部访问，两种连接的外部请求均为零，原件和登记哈希未改变。WFS / OSM 的独立格式检查读取已保存的原始响应；不能把它写成再次查询公开服务器。ArcGIS 另有真实重新请求记录。

可追溯汇总见 [协议验收记录](../prototype/qa/agent-vector-protocols-verification.json)，其中保留完整原文件与转换哈希、实际模型和离线 MCP 证据路径。公开 QA 契约在 `scripts/acceptance/vector-*-public.json`，仅是显式验收输入，不是软件默认服务，Overpass 失败不会自动重试或改换公共端点。复验向上述模型脚本追加 `--vector-source <QA 契约>`；`--source-direct` 只改变隔离测试目录的来源连接路线。
