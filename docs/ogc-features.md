# OGC 矢量数据服务

在“我的数据 → 矢量文件 → 获取矢量数据”添加公开 HTTPS OGC API Features 服务，选择集合，按探索页当前范围提取要素并保存到本地。连接可刷新或移除；移除连接保留已提取文件。桌面原生命令与开发浏览器共用同一个 Rust 运行时。

本功能按 [OGC API Features Core](https://docs.ogc.org/is/17-069r4/17-069r4.html) 的入口、标准声明、集合和分页链接发现资源。只接收声明 Core / GeoJSON、提供 JSON 元数据与 GeoJSON items 链接的服务。集合描述和数据许可保留服务原有内容；未声明许可链接时不把服务软件许可当成数据许可。

## 提取和持久化

查询使用 WGS84 经度、纬度顺序的外接矩形。所选多边形另存为查询来源记录；**保留服务返回的完整几何和原始属性，不隐式裁剪**。提取时间是请求时间，不是要素观测时间。本次查询收齐不代表下载了整个数据集。

跟随同一服务、同一资源的下一页，检查范围、唯一分页地址、服务声明的数量和重复编号。相同编号且内容一致的重复要素合并，内容冲突、数量变化、提前结束或超过上限时整个提取失败，不登记部分文件。没有编号的要素保持独立。整数超出 JavaScript 安全范围时拒绝读取，需由服务以字符串返回。

上限以先达到者为准：25 页、5 万要素、20 MiB 响应、120 秒网络提取；最终 GeoJSON 也受现有 20 MiB / 50 万坐标限制。提取完成后才写入受管文件并原子登记。网络超时不会中断正在提交的本地文件。

文件和导出的 `geodSource` 保存服务与集合身份、查询范围、多边形记录、提取时间、逐页地址 / SHA-256 / 字节数 / 返回数量、完整匹配查询计数及声明的许可链接。重新查看或导出会核对保存文件的 SHA-256 和来源记录。普通本地 GeoJSON 中自行提供的 `geodSource` 不会自动变成可信服务来源。

连接和文件登记分别保存在当前软件数据目录的 `feature-services.json` 与 `vectors.json`。原文件内容在 `vectors/`，重启后可离线显示和导出；查询时仍访问原服务。

网络遵循全局的跟随系统 / 直连 / 自定义代理设置。地址限制为公开 HTTPS，禁止凭据、片段、跳转和跨服务链接；解析到内部地址时拒绝连接。直连固定经过检查的 DNS 地址，代理服务器可能自行解析目标域名。私人 HTTP 服务、令牌 / API Key 服务和跨主机资源尚未支持。

## 实际验收

[验收记录](../prototype/qa/ogc-features-verification.json)使用维护者提供的 [pygeoapi 公开测试服务](https://demo.pygeoapi.io/stable)，从 Large Lakes 集合提取真实 Natural Earth 湖泊数据：13 页、25 个 Polygon。独立重新获取源分页后，所有编号、几何和属性与应用保存内容一致；Shapely / GEOS 核对几何有效性、范围与查询相交。

英文浅色 1440 像素和中文深色 1024 像素界面完成区域设置、集合刷新、真实提取、实际地图点击属性、来源展开和浏览器导出。两个区域查询各返回 13 个要素 / 2 页。停止服务后，三个验收文件的本地恢复、完整来源、原文件校验与桌面共用原生导出逐项通过。

验证使用独立数据目录和无界面的测试浏览器，没有操作用户桌面。桌面命令及权限编译通过；本轮没有实际操作 Windows WebView 窗口。测试服务不保证生产可用性；其他集合目前只完成元数据发现，没有逐一验收原始要素。

## 命令行

`feature-services list|forget --id UUID`、`feature-services connect|query --request FILE` 支持独占 `--data-dir DIR` 或连接已有 `--server http://127.0.0.1:4318`。连接请求例：

```json
{"name":"公共矢量服务","url":"https://demo.pygeoapi.io/stable"}
```

查询请求中的 `serviceId` 来自连接结果：

```json
{"serviceId":"连接结果中的 UUID","collectionId":"lakes","bounds":[-130,20,-60,65],"areaGeometry":null,"pageSize":200}
```

`pageSize` 可选，1–200，服务可能返回较小页；仍按 next 链接读取。文件继续使用 `vectors inspect|export` 的既有流程。可用 [真实验收脚本](../scripts/verify-ogc-features.py) 在独立运行时重新核对公开服务；脚本不是运行时依赖。

此适配不代表 WMS / WMTS / WCS、通用 STAC / COG 或在线 OSM 已接入。矢量任务队列、断点续取、精确几何裁剪、栅格叠加、属性筛选、时间筛选和工程内矢量处理仍待实现。
