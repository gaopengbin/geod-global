# Landsat 质量文件工程处理

2026-10-04。Landsat 8/9 Collection 2 Level-2 的 `QA_PIXEL`、`QA_RADSAT` 已支持单景按工程区域裁剪、多景同网格拼接，以及带孔洞多边形裁剪。输出保留完整 UInt16 原值、30 米网格和独立 TIFF 内部覆盖掩膜。原文件查看的历史验收见[原始质量文件](landsat-quality.md)，本轮处理和实际 Landsat 8 / 9 文件证据见[机器记录](../prototype/qa/landsat-quality-processing-verification.json)。

## 软件内操作

在 Landsat 工程下载像元质量文件和饱和质量文件，再使用对应的「按工程区域裁剪质量层」或「拼接并裁剪质量层」。饱和层处理需要每一景匹配的像元质量文件；缺少配对时按钮禁用并说明原因，原生接口也会拒绝排队。下载内容可以一次选择 RGB 与两种质量层，也可以单独补齐所需文件。

任务完成后，工程文件卡片可立即打开结果到工作空间。打开刚完成的文件时先取得新的任务记录，避免旧列表把它误判为不可用。结果支持地图显示、原始整数取值、位字段解码、完整分辨率统计、只读 MCP 和持久化缩略图；图层选择器不重复显示质量层名称。

## 原值与覆盖规则

位定义沿用 [USGS Collection 2 Quality Assessment Bands](https://www.usgs.gov/landsat-missions/landsat-collection-2-quality-assessment-bands)。处理不套用反射率的 scale/offset，不平均数值，也不把不同景的质量位按位合并。

- `QA_PIXEL` 第 0 位表示填充。保留完整 16 位原值，包括填充值同时携带的其他标志。
- `QA_RADSAT` 的 0 是有效原值，不能用它推断覆盖。每景必须配对同一原始影像、同一处理目录及同一网格的 `QA_PIXEL`，两份文件的 SHA-256 分别固定在任务中。
- 重叠区按日期从旧到新选取最新非填充景的整个质量样本。新景填充不擦除旧景已有覆盖；没有覆盖时仍保留对应的完整原值。
- 工程外、孔洞及来源间隙通过独立的 1 位 TIFF 内部掩膜表达。饱和层在已覆盖和未覆盖区域都可能存储 0，掩膜明确区分两者。

成果不声明单一数值的 GDAL NoData，采用 PixelIsArea 网格。原件的 PixelIsPoint 样本中心保持不变，外边界正确换算半个像元，输出不重采样。TIFF 描述保存 `geod-landsat-quality-mosaic/v1` 规则，并与任务记录核对。

完整位字段统计包含成果中全部存储样本，也包括未覆盖区域和保留编码；地图显示分类统计仅计已覆盖样本。显示颜色按优先级分组，一个像元仍可同时具有多个标志。该处理保留质量信息，**尚未自动筛选 RGB 或去云**。

| `LC08_L2SP_045034_20250627_02_T1` | 四份新原生下载之一 | 1,333,817 | 230,524 |
| `LC09_L2SP_044034_20250628_02_T1` | 复用已验收完整原件，重新核对 SHA-256 | 986,984 | 224,657 |

六份文件均为 EPSG:32610、30 米、UInt16、单波段、PixelIsPoint。原件地址保留原始处理版本，没有持久化访问签名。新取得四份完整原件，另两份沿用此前真实下载；后续处理及界面重试复用已完成文件，没有把重复处理记作新下载。

| 三景矩形拼接 | 4121 × 1860 | 7,665,060 | 7,665,060 | 0 |
| 三景带孔多边形 | 4121 × 1860 | 7,665,060 | 7,370,606 | 294,454 |
| 较大三景区域 | 4126 × 2415 | 9,964,290 | 9,964,290 | 0 |

Rasterio 1.3.9 / GDAL 3.6.4 与 tifffile 独立读取全部 **64,025,460 个输出原值及同数量的覆盖位**，逐一比较参考拼接、完整字段分布、无符号类型、源网格、预览和缩略图。实际重叠区验证了新景填充时保留旧景数据；饱和层同时验证有效零值和未覆盖零值。较大成果实际超过此前八百万像素边界，按块处理及精确原值通过。

缺少配对文件的工程返回明确错误且不创建任务。直接和本地服务两种只读 MCP 模式覆盖全部八份成果，共 188 次原值查询；断开服务后拒绝查询。八份成果复制到没有任何父级原文件或父级任务的隔离工作空间后，原值、地图和缩略图仍可读取。

不可达上游代理下重启，八张缩略图的内容、文件身份和创建时间保持不变；LRU 修改时间可以更新。改动成果会拒绝已有缓存，损坏缓存 JSON 后重新生成相同图像。详见[缩略图缓存](thumbnail-cache.md)。

生产前端在 1440 英文浅色、1024 中文深色、900 中文深色三个视口通过：实际工程按钮生成新的原生成果，其完整文件哈希、来源和处理计划与独立验收成果一致；地图共比较 913,920 个源预览 RGBA 像素，检查原值、全部位字段和 69 个已显示统计项。没有外部请求、页面 / CSP 异常或横向溢出；截图已实际查看。

运行时全量回归 469 项通过、4 项明确忽略；严格运行时 Clippy、格式、仓库隔离、相对文档链接、桌面命令权限、契约及配方检查通过。相关界面回归 28 项和生产前端构建通过。本地模拟下载测试显式直连测试服务，避免开发机器的系统代理影响测试；生产代理逻辑不因此改变，受保护账号的真实授权验收仍未完成。

真实雪、地形遮挡和非零未使用位尚不构成完整正例矩阵。高位原值、填充回退、条带边界、孔洞、有效零值及中途取消另有明确的合成回归，不能把合成正例标为实际卫星观测。

## 剩余范围

本轮仅处理对齐的 30 米 Landsat 8/9 C2 L2 质量网格。该工程质量处理验收不包含 RGB。后续 Landsat 9 同景原件 / 单景成果的[科学 RGB 质量筛选](landsat-rgb-quality-mask.md)已另行通过真实验收；Landsat 8 RGB、多景联合质量选景、其他 QA 层、通用跨网格重投影和工程拼接成果的通用 ZIP 交付包仍待验收 / 接入。自包含 GeoTIFF 的读取不依赖父级文件，不等同于通用 ZIP 包已经支持。

隐藏浏览器中的生产资源、桌面 CSP 与真实原生桥接已验收；原生 WebView 窗口、安装包和完整发布验收仍另行完成。本轮没有制作安装包或远程发布。NASA / Copernicus 的[软件内授权入口](provider-accounts.md)沿用现有实现；没有账号时保留受保护生产下载待验收状态。完整剩余能力见[接入状态](provider-integration-status.md)。
