# Agent 文档附件

音视频附件按用户决定暂缓，不属于当前 Agent 接入验收范围。已有局部实现与历史记录保留，下面音频描述仅记录此前进度，不表示完整可用。暂缓期间不再增加相关功能、格式、协议、测试、真实模型调用或验收材料；当前工作继续优先图片、文档和 GeoD 业务流程。

2026-10-06。对话输入框的回形针可添加图片、PDF、DOCX、XLSX、PPTX，以及 UTF-8 编码的 TXT、Markdown、CSV、JSON 和 GeoJSON。每条消息合计最多 3 个附件；图片、PDF 和 Office 每份最多 2 MiB，文本文件每份最多 64 KiB。PDF 须为未加密的 1 至 20 页文档；Office 须为未加密、不含宏的 OOXML 文件。较大的栅格或矢量数据继续使用工作空间的导入与业务读取入口。

文本文件显示为文件名和大小的紧凑卡片，点击后查看纯文本预览。文件中的 HTML 不会执行；内容原样保留，包括中文、换行和 UTF-8 BOM。它用于对话分析，不会自动导入图层、执行文件内容中的指令或提交计划。JSON / GeoJSON 在此作为文本资料传递，不声明其几何或格式已经通过业务校验。

PDF 使用同一文件卡片。点击后按页预览，上一页、下一页和页数统一使用软件组件。PDF.js 的 worker、字体、字符映射和解码资源随本地界面保存，不依赖外部预览网页。预览使用画布，不执行附件脚本、不激活链接或表单；保留现有桌面 CSP，不启用 iframe 或原生 PDF 插件。

Office 点击后显示内容预览。Word 保留段落、表格行列和相关页眉页脚文本；Excel 显示工作表名称、单元格地址、保存值和公式原文，不计算公式；PowerPoint 按演示文稿实际顺序显示幻灯片文字。预览支持 OOXML 的 UTF-8 / UTF-16 文本，不声称还原页面排版、图片或图表。源码中的 HTML、宏与公式均不执行，也不访问外部关系或解压到文件系统。

Office 包限制为最多 512 个条目、单条目解压最多 4 MiB、总解压最多 16 MiB，内容预览最多 256 KiB；超限明确拒绝，不悄悄截断。存储标识绑定原文件字节和 MIME，不依赖预览排版；临时预览字符数独立校验。

音频保存原文件，点击卡片后使用软件统一的播放、暂停和进度控件试听，不自动播放。Symphonia 0.6.1 在后台工作线程中实际解码，核对格式、单轨音频、1–8 声道、8–192 kHz 和时长，拒绝改名伪装、不支持的编解码器、损坏或超限内容。解码不累计完整 PCM，元数据标签有界，封面图片不读取；试听失败不会改变保存的原文件。音频哈希绑定原 MIME 和字节，时长等临时预览信息不参与存储标识。

桌面端检查实际内容、大小和文件名，把副本保存在应用自己的附件目录。文本检查 UTF-8 和控制字符，PDF 使用 lopdf 解析结构、确认页数并拒绝加密文件，单个压缩流的解压上限为 8 MiB。PDF 的哈希同时绑定 MIME 类型、页数和原字节；文本原有哈希保持兼容。会话记录只存哈希、文件名和有界元数据。继续对话前核对副本哈希及历史元数据，文件缺失或被改动时拒绝新提交并保留历史。发送失败保留草稿，成功后显示在会话中。

重启后沿用同一会话引用；上下文整理之后会恢复所选附件，包括对话中途整理的情况。恢复保持原有工具调用配对、连接隔离和人工计划确认。文本内容作为用户资料传递。PDF 的私有编排输入保存有界引用，适配桥在当前会话的每一步按引用恢复原文件，使用 AI SDK 的 `file` 内容类型和 `application/pdf` 传递原字节，不提取文本替代 PDF，不读取任意文件路径或远程文件 URL。

PDF 读取取决于所选模型和接口。接入文件内容类型不表示所有模型都已支持 PDF；[AI SDK 文件输入](https://ai-sdk.dev/docs/foundations/prompts)和 [OpenAI PDF 输入](https://developers.openai.com/api/docs/guides/file-inputs)均有模型能力要求。软件内“发送哪些内容？”说明原文件会发送给当前模型；接口拒绝时显示失败，保持历史，不自动切换模型或协议。

Office 原文件目前限 OpenAI 原生 Responses 连接；界面在不支持的连接中仍允许本地预览，并阻止发送，私有会话服务也在记录新消息前拒绝。桥接层只对已验证的 Office 引用启用固定 SDK 的文件透传选项，保留原字节、原 MIME 和文件名；不把 Office 改成文字或 PDF，不放宽其他协议和编排输入限制。模型、接口及其文件读取器仍决定实际读取范围：OpenAI 的文档输入不包含内嵌图片，表格读取最多覆盖每表前 1,000 行。[接口文件输入说明](https://developers.openai.com/api/docs/guides/file-inputs)

音频原文件发送限 Google 原生连接，其他连接仍允许本地试听，并在新增消息记录之前拒绝发送。当前会话的恢复和上下文整理继续提供原文件，不转写为文字、不转码、不访问附件 URL，也不切换协议。Google 内联请求有 20 MB 总量限制，软件在联网之前按最终请求体检查文字、工具和附件编码后的总大小。[Google 音频输入说明](https://ai.google.dev/gemini-api/docs/audio)

每段对话最多 8 份不同文档，文本合计最多 256 KiB，PDF、Office 与音频合计最多 8 MiB，图片与文档的原字节合计最多 20 MiB；Google 的上述编码后请求限制另外检查。文档副本存储上限 32 MiB，图片上限保持 128 MiB。在“对话历史 → 附件存储”查看两类占用，明确点击“清理未使用副本”。清理核对所有模型连接的会话引用，并保留当前草稿；未知文件、原文件、工作空间数据和私有恢复记录均不删除。

PDF 的原生保存、页数校验、引用保护与损坏拒绝已通过针对性检查。实际 OpenAI SDK 的受控本地请求收到与原生保存相同的 PDF 字节；上下文恢复、适配桥重启和会话隔离也已核对。隐藏浏览器在生产界面和桌面 CSP 下完成两页画布渲染、翻页、文件卡片与按引用发送。

Office 的三种原生格式、Unicode 内容、共享字符串、公式不执行、幻灯片顺序、损坏与解压上限、清理保护已做针对性检查。实际 SDK 的受控本地请求收到三份原文件；桥接重启与会话隔离、协议拒绝在写入历史前发生，均已核对。界面检查使用原生摄取结果，预览及发送状态为界面回调，不是原生窗口或真实模型识读验收。

音频的四个解码分支、时长和大小拒绝、错误 OGG 编解码器、损坏及清理保护已通过针对性原生检查。实际已安装 Google SDK 的受控本地请求收到与原生保存一致的四份原字节，桥接重启、会话隔离、发送前协议拒绝和最终请求体超限均通过。隐藏浏览器在桌面 CSP 下完成 WAV 加载、静音播放、暂停和键盘拖动进度，使用真实原生摄取元数据，发送转换为受控界面回调。附件命令也补入桌面主窗口权限清单。未操作用户桌面，未把组件或隐藏浏览器当成原生 WebView 人工验收。此前 Google 云端路线的 500 错误保留，本轮未再次请求外部模型，不宣称真实云端音频识读通过。

没有运行完整验收或制作安装包。旧版 DOC / XLS / PPT 与其他 Office 类型为后续候选，不加入本轮；音视频暂缓，既有代码保留并从当前验收范围排除。当前开发入口见[开发版说明](development-preview.md)。
