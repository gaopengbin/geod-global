# MODIS 五类文件的工程裁剪与拼接

2026-10-04。MOD09A1 / MYD09A1 Collection 6.1 的红、绿、蓝反射率波段及 QC / State 两个质量层，现在均可从工程页裁剪或拼接到工程区域。五类文件分别输出单波段 GeoTIFF；原件来自 Planetary Computer 转换的 COG，不是 NASA 原始 HDF。

## 使用与处理规则

下载质量文件后，在工程的「MODIS 波段质量」或「MODIS 像元状态」区域选择「裁剪质量层」或「拼接并裁剪质量层」。结果归入当前工程，可打开本地地图、读取像元、解码质量标记，并在重启后复用持久化缩略图。反射率与质量文件各自检查下载完整性，不能混用。

QC 保留 UInt32 和填充值 4294967295，State 保留 UInt16 和填充值 65535。0、最高位及未定义代码均按原值保留；填充值不解码为有效标记。输出嵌入产品、质量层、位数和 [NASA C61 定义](https://landweb.modaps.eosdis.nasa.gov/data/userguide/MOD09_User_Guide_V61.pdf)，没有反射率 scale / offset。三个反射率波段继续保留 Int16、−28672 NoData、scale 0.0001 和 offset 0。

处理使用原始正弦投影和对齐像元网格，不重投影或重采样。矩形生成向外对齐的源网格包围窗口；多边形按像元中心判断外环和孔洞，区域外填入该数据层的原始 NoData。相邻瓦片和重叠时段按合成起始时间、再按产品 ID 排序，较新的非填充值覆盖先前值，较新的填充值保留先前有效值。每个质量像元整体复制，不合并各位，不根据质量等级选择观测，也不自动遮罩 RGB 或反射率。

输出按条带写入压缩 GeoTIFF，完成后完整回读像元字节、空间标签和校验值。输入类型、填充值、产品、位定义、投影或完整 SHA-256 不符，以及取消操作时，均不提交成功结果。详见[反射率工程处理](modis-processing.md)和[原始质量层解码](modis-quality.md)。

## 边界与复现

当前不执行云 / 质量掩膜、质量优先合成或其他科学分析。通用重投影、其他 MODIS 产品、NASA 原始 HDF 和未持有账号的受保护产品仍未验收。读取和查看质量层不代表已授权下载 NASA / Copernicus 受保护原文件。

界面验收采用无头 Edge 和真实隔离运行时，没有操作用户桌面；桌面开发程序已更新，安装版 WebView 人工验收仍待完成。本轮未生成安装包或公开发布。
