## 原始网格、单位和声明冲突

### SGLI 海面温度

真实东北 TIFF 为 3,600 × 3,600、单波段 UInt16、EPSG:4326，bounds `[90,0,180,90]`，原始间距 0.025°。完整 12,960,000 像元独立解码，6,516,561 个数值有效 DN、6,443,439 个 NoData。原始 NoData 为 **65535**；零不属于该 NoData。

STAC 精确声明温度［℃］＝ **DN × 0.0012000000569969416 − 10**，TIFF 自身内嵌 scale 1／offset 0；物理换算依据原始 STAC，存储 DN 不变。东北原件 DN 5726–36505 与该 Item min/max 一致，不能当作全产品统一质量门限。任务文档保留的错误码 65532–65534 在本原件中均未出现；当前 COG 条目只声明 65535，未提供独立 QA 或海洋掩膜。内陆亦存在非 NoData 数值，因此数值范围本身不是海洋有效观测证明。

东北真实区间是 **2026-09-01T00:25:58Z 至 2026-09-30T11:03:17Z**，不是人为补齐的整月午夜区间。10 月创建时间不是 10 月观测。`je:img_level` 为 overview，TIFF 保留 MODE 概览重采样；不宣称 250 米细节或未经验证的时间平均。东海样点 DN 30952，按精确声明为约 27.1424 ℃。

Collection 通用 ID `collection` 与 Item 完整产品 ID 的冲突原样归档；产品专用校验绑定精确网址和完整文档，不制造别名或宣称集合 ID 已匹配。许可为 **proprietary／JAXA 研究数据条款**：须注明 JAXA、研究名称及相关机构；商业使用须提前通知 JAXA。本轮没有发送通知，公开免费获取不等于 CC 许可。

### 年度夜光

正式作者完整文件为 **86,400 × 35,849、单波段 Int16、EPSG:4326、PixelIsArea**，512² tiled，原始间距 0.00416666666666667°（15 角秒），实际 bounds 为 `[-180,-62.000833333333446,180.00000000000028,87.37]`。名义 500 米不是全球恒定地面分辨率；显示／查询经度边界处理不改变原始 transform。

这是作者处理 DN。作者说明 0–200 缩放到 0–2000，而实际 TIFF scale 为 **10**、offset 0、无 unit；该冲突保留，不能猜成 0.1、`nW/cm²/sr` 物理辐射或旧集合的 proportion。NoData 仅为 **−32768**；零、负非缺失值和 32767 保持原值，不补造质量掩膜。年度参考区间由客户端配方声明，不伪造原件中不存在的观测时间戳。

在线灰度配置 **0–200 仅用于显示对比度**，不裁断下载文件、不改写原值，也不将其当作物理单位范围。最终页面刷新后重新检索和加载通过，状态为“预览已显示”，截图目视可见北京区域的亮点与明暗变化；此前 0–2000 显示偏暗的截图独立保留。原始像元仍为 150。原生 PNG 的自适应灰度采样与在线显示设置分开记录。保留正式作者 **CC BY 4.0**、版本、作者／OpenGeoHub 与 EOG 来源署名；一个 2024 原件成功不代表全部年度或整个 OpenLandMap 平台已验收。
