# Sentinel-1 IW RTC 接入与实际原文件验收

2026-10-02。已接入 Planetary Computer 的 Sentinel-1 IW RTC 集合。它是供应商从 ESA GRD 产品生成的地形校正后 gamma0 COG；供应商为 Catalyst / Microsoft，集合许可为 CC-BY-4.0。GeoD 读取这个产品，不自行执行原始 GRD / SLC 定标或地形校正。[官方集合与处理方法](https://planetarycomputer.microsoft.com/api/stac/v1/collections/sentinel-1-rtc)

## 软件中的流程

探索页可选择 Sentinel-1 IW RTC，按区域、UTC 日期、升降轨和极化检索，目录分页保留这些条件。当前官方接口不支持所需的极化数组查询，因此按每页实际可下载资产筛选，继续读取被全部过滤的页面；不使用光学云量筛选，也不把供应商浏览图当成原文件。

选景后可下载同一工程内可用的 VV / VH / HH / HV 单极化原文件。下载端逐份核对官方目录身份、极化、完整无签名路径、Float32、10 米和 -32768 NoData，使用容器级临时只读 SAS。签名仅存于内存，不进入任务、工程或来源记录；每份经审核的 RTC COG 上限 4 GiB，其他普通栅格上限仍为 512 MiB。

官方集合说明目前写明需 Planetary Computer 账户，本轮官方 SAS 接口实际成功授予读取并完成下载。记录两者差异；不承诺永远无需账户，不绕过供应商拒绝或限流。[官方访问说明](https://planetarycomputer.microsoft.com/docs/concepts/sas/)

下载检查文件签名、传输长度和 SHA-256；没有在提交下载时解码整份大型栅格。检查栅格和原值取样另行重新核对整份文件的 SHA-256，并从同一打开文件读取 GeoTIFF 几何和原始 Float32。它们支持 WGS84 UTM、10 米 PixelIsArea 网格。文件存在、浏览图可见不代表所有像元或地形校正精度已验收。

工作空间和缩略图使用有效 gamma0 的 `10 × log10(value)`，基于显示采样的 2%–98% 范围拉伸。负值只允许 -32768 NoData，NoData 透明；0 是有效线性值，显示为黑色，不制造有限 dB。像元取样始终读取全分辨率原值，显示时不会改写文件。界面清楚区分原始 gamma0 和显示 dB，预览可使用文件中经过检查的概览层。

缩略图复用原生持久化缓存：首次由经校验原文件生成，后续以托管文件身份、大小、创建 / 修改时间和记录校验值判断命中，核对缓存 PNG 自身哈希。实际服务重启后再次命中，缓存内容保持一致，没有重新生成原文件预览；缓存条目的修改时间会按最近使用更新以便淘汰。缓存不等于每次重新校验整份原文件；原值检查仍执行完整 SHA-256。

## 一份真实原文件的证据

原生运行时在隔离验证目录完成以下整文件下载，未使用用户桌面或响应夹具来替代原文件：

| 项目 | 实际值 |
|---|---|
| 场景 | `S1C_IW_GRDH_1SDV_20250630T140654_20250630T140719_003013_rtc` |
| 极化 | VV |
| 下载字节数 | 1,840,806,210 |
| SHA-256 | `e869896b958541b46062f930c300a0554dd9ae7fa9a7feb1fc1d803ede4dcb7d` |
| 栅格 | 27195 × 20629，单波段 Float32 |
| 坐标系 / 分辨率 | EPSG:32610 / 10 米 |
| 外边界 | `[534370, 4087010, 806320, 4293300]` |
| NoData | -32768 |

独立 GDAL/rasterio 读取全分辨率的两个有效像元和两个 NoData 像元，与 Rust 返回的 Float32 转 f64 值逐值一致；两个有效值为 `0.0861993357539177` 和 `0.005583649501204491`。独立工具另外核对全部 446,976 个预览 RGBA 像素及 160 像素缩略图，完全一致。验证工具为 [verify-radar-original.py](../scripts/verify-radar-original.py)，应用运行不依赖 Python / GDAL。

同一份原文件通过实际原生服务接入前端工程缩略图和工作空间地图；1440 宽英文浅色、1024 宽中文深色的无头界面验证无页面错误或横向溢出。它验证前端与原生数据链路，没有操作用户桌面，也不替代安装版 WebView 验收。[精简验收记录](../prototype/qa/radar-native-verification.json)

开发模式下整文件重校验约需 24 秒，每次原值取样约需 23 秒；缩略图命中约 31 毫秒。大文件交互性能仍需优化，优化必须保留校验边界。计时取决于机器、构建模式和本地磁盘，不能用作发布版性能承诺。

## 尚未完成

RTC 工程裁剪及对齐网格拼接已接入；两份完整 VV 原文件生成的矩形、带孔洞多边形和双景成果均经独立逐位核对，见[工程处理验收](radar-processing.md)。本轮第一份完整 VH 原件的校验、原值、预览、只读 MCP 和生产前端显示已通过，见[极化扩展进度](radar-polarizations.md)；其余 VH / HH / HV 原件及扩展处理成果仍在验收。这些来源不代表供应商全域产品已验收。不同网格覆盖与供应商地形校正精度需单独验证。滤波、分类、时序变化分析及原始 GRD / SLC 处理未接入。NASA / Copernicus 原文件的成功授权验收仍待用户账号，软件内授权入口继续保留。
