# NAIP 自然色、红外假彩色与近红外显示

2026-10-04。已下载的 NAIP 四通道原文件和匹配的工程成果，在工作空间地图工具栏使用同一个选择器切换显示方式。沿用 Beautiful UI 的控件与主题。

| 显示方式 | 显示 R / G / B 使用的原始通道 |
|---|---|
| 自然色 | 红 / 绿 / 蓝，1 / 2 / 3 |
| 红外假彩色 | 近红外 / 红 / 绿，4 / 1 / 2 |
| 近红外 | 近红外灰度，4 / 4 / 4 |

红外假彩色采用 [USGS NAIP 服务](https://imagery.nationalmap.gov/arcgis/rest/services/USGSNAIPImagery/ImageServer/rasterFunctionInfos)列出的通道组合。软件当前显示原始 UInt8 数值，没有套用该在线服务的拉伸或分析函数。

切换仅改变预览颜色。原文件、四通道处理结果、固定源清单、网格、完整 SHA-256 和原始 RGB / NIR 像元读值保持不变。第四通道始终是 NIR，不能用作 alpha；有效的黑色 RGB 和零 NIR 保持可见。工程结果的透明度来自独立内部覆盖掩膜，三种显示使用相同掩膜。

已加载图层在内存中复用三种预览；卸载图层释放这些预览。文件卡片继续显示自然色缩略图，复用现有磁盘缓存。切换显示不会向磁盘缓存写入另外两种缩略图，也不改变工程中的处理通道定义。重新打开图层采用自然色。

原生 HTTP 检查接受 `aerialView=rgb|cir|nir`，桌面 `inspect_raster` 接受对应可选参数；旧调用默认自然色。无效选择和非 NAIP 文件拒绝请求。前端核对返回的通道、文件哈希、源网格、覆盖掩膜与原额外采样标签，防止把不同图层或错误视图替换进地图。

## 实际验证

独立检查使用此前完整接受的 0.3 米 / 1 米三份原文件与五份工程成果，文件身份和来源见[分辨率变体](naip-resolution-variants.md)。验证建立单独离线工程副本，复制完整清单文件，只读使用相同 TIFF 字节，没有更改原工程。

GDAL/rasterio 与 NumPy 独立读取对应概览及四个通道，核对八份文件的 24 张 PNG，共 **12,174,336 个 RGBA 像素**；各通道和覆盖 alpha 全部一致。另核对 24 个原分辨率点的 RGB 与 NIR。切换后五份处理计划仍固定 1 / 2 / 3 显示定义，四通道内容没有变化。无效显示参数被原生服务拒绝。

八张自然色缩略图的缓存内容和文件身份在显示检查期间保持不变。随后关闭并重启隔离运行时，上游连接被拒绝，八份文件和八张相同缩略图恢复，缓存内容与文件身份一致。

生产渲染器在 1440 / 1024 / 900 像素、中英文和明暗主题中完成八组实际地图切换检查。三种显示的 **4,145,416 个地图像素位置**逐通道一致，透明度一致；32 次原始像元读取保留相同坐标、RGB 与 NIR，切换保留地图缩放和视野。每个图层三次返回已加载视图均使用内存预览，不增加检查请求。没有页面异常、CSP 违规、远程请求或水平溢出；缩略图、自然色 / 假彩色及带孔结果截图已复查。

OpenLayers 会把范围线和像元标记合并到影像画布。颜色检查读取影像实际绘制后的快照，再单独查看包含这些覆盖线的完整截图；观察程序先调用原始 `drawImage`，不替换预览、目录、渲染器或覆盖线。六组已通过检查按原生、独立报告、前端资源及 18 张画布图的哈希恢复；两份 0.3 米成果使用该绘制观察方式完成检查，未复用失败的颜色比较。大原件每次原值读取前执行完整文件校验，界面检查采用软件相同的 60 秒等待上限，本轮最慢请求约 38 秒。

[机器记录](../prototype/qa/naip-views-verification.json)现为 `passed`。[独立图像检查](../scripts/verify-naip-views.py)、[生产界面检查](../scripts/verify-naip-views-ui.mjs)及[证据汇总](../scripts/summarize-naip-views.py)保留完整文件、预览、前端资源和报告的哈希绑定。缓存只代表自然色缩略图持久化，不能据此声称假彩色预览或科学分析结果已经写入磁盘。
