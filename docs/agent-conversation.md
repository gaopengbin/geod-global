# 自然语言任务执行

数据交付需求现已接入[Codex 目标模式](agent-goals.md)：保存完整目标和必需成果清单，等待决策或任务确认，后台任务结束后检查实际成果再继续。回复结束不等同于目标完成；对话里可查看每项成果并暂停、继续或清除目标。

GeoD Global 的桌面开发版使用现有 Codex 会话和 GeoD 任务引擎完成连续任务。实现参考了独立 `geod-agent` 仓库中的会话权限与原生执行检查，没有运行时路径依赖、第二套下载器或 AI SDK 的第二个 Agent 循环。

## 对话界面与流式输出

输入框移植自 `geod-agent` 0.2.3 的 `prompt-input.tsx`、输入框控件与对应样式，接入 Global 现有 Beautiful UI 适配层。完整来源、实际文件哈希、许可和兼容修改记录在 [输入框移植记录](../licenses/geod-agent-composer-source.json) 和 [原始 MIT 声明](../licenses/GeoD-Agent-Composer-MIT.txt)。消息阅读和执行记录参考同项目的 `chat-ui.tsx`、`message-scroller.tsx`；运行时只使用本仓库组件与依赖。

- 输入框保留 24 像素圆角、12 像素内边距、15 像素文字与 24 像素行高，工具栏在框内按“加号附件、权限、上下文用量、模型、发送／停止”排列。图片和文档预览位于框上方。常驻的底部说明与第二行权限栏已移入相关弹窗。
- 输入栏只显示模型名，常规名称按内容宽度显示，长名称最多占 180 像素。208 像素弹出菜单保留源组件的紧凑行，显示连接名与模型，最后一项带机器人图标，可打开模型连接设置。它切换保存的连接；设置页保留供应商分组和连接测试。
- 加号菜单保留图片、文档、音频、音频设置、数据范围的顺序及 Lucide 图标，接入现有本机附件与模型设置入口。音频使用支持的 Google 原生连接读取，数据范围接受 GeoJSON 文件；上传大小、会话绑定和原生权限沿用现有规则。
- 上下文圆环使用最近一次原生模型请求的用量；未收到用量或窗口上限时明确显示未知。上下文整理和“发送哪些内容”说明位于同一弹窗，避免输入框下方重复占位。
- Codex 的真实文本增量更新会话后，Node 最多每 32 毫秒通知原生宿主一次。宿主只向 `main` 窗口发送安全整数修订号；界面重新读取并校验原生快照，不接收未经校验的文本或工具参数。只开放事件监听与取消监听，没有开放 JavaScript 事件发送。
- 回复逐段显示并带流式光标；空回复等待状态使用动态圆点。停止后保留已收到的内容并移除光标，已完成或中断的回复可以复制。复制不调用模型。
- 用户消息、助手正文、执行过程和方案确认分开显示。连续执行记录和紧接工具调用的过程说明收在可展开记录中；确认方案保持可见，不藏进执行记录。
- 处于最新消息位置时跟随真实内容增长。上翻历史或查看执行详情后保留阅读位置，只有确实存在下方内容时显示“回到最新消息”。文本高度采用源组件的独立测量节点，在空输入和面板缩放后恢复到 48 像素；长输入最多增长到 144 像素。中文输入法的回车不会误发。

可复核脚本：`scripts/verify-agent-stream.mjs` 通过准备好的 Node、实际 Codex 进程、AI SDK 及本地受控 SSE 服务验证逐段传递；`scripts/verify-agent-chat-ui.mjs` 在隐藏浏览器中验证实际 React 界面和受控 IPC。前者不代表真实模型智能验收，后者不代表原生 Windows WebView 录像；两者均不调用付费模型、不修改用户连接，也不操作用户桌面。记录见 [对话界面验收](../prototype/qa/agent-chat-ui-verification.json)。

## 使用

追加裁剪等处理要求会修订当前目标，保留已有来源和区域约束，并将处理后的成果作为最终交付。搜索和任务卡具有原生有效期；过期搜索的明确错误允许按原条件重新检索，新任务卡仍需独立确认。没有可用行政区多边形时，Agent 用选项卡区分外接矩形裁剪和提供真实边界，不能将矩形称作行政区精确裁剪。

DeepSeek 兼容连接的每次输出预算为 16,384 tokens，保留同一模型、协议和工具推理历史。当前 flash/pro 模型采用官方 `low` 思考强度以适合交互；其他连接保留原预算和强度。达到长度上限但尚未产生正文的流明确报长度中断，不误报空回复，也不算任务完成。参见 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。

默认使用“每次确认”。先描述任务；确需用户决定的范围、质量或交付选择会展示为选项卡，支持选择已有方案或填写其他偏好。推荐项不自动选中，回答会保存到历史；提交选择不会批准下载。下载前显示完整任务卡，包含需求、已选方案、实际原生文件范围、请求时段、容量、输出和限制，确认后才提交真实任务。未回答的问题会阻止确认；任务卡之后选择改变，需要重新准备或修改任务卡。

如果明确希望免询问、自动执行，在输入框内打开权限菜单，选择“完全访问”，或单独发送“开启自动执行”“不用问我”。这个许可只由用户原生操作授予，选项答案和模型文本不能替代。然后描述任务，例如：

> 检索当前地图范围和日期内的一景 SCL 影像，保存为工程并下载，下载完成后按当前范围裁剪，检查成果并在地图里打开。

“每次确认”会生成待确认方案。可以在对话里输入“确认执行”；有多个方案时输入“确认全部方案”。仍可使用方案卡片修改参数或确认。切换模式也可在对话里输入“开启自动执行”或“关闭自动执行”。“完全访问”沿用本产品的受管理工程和文件权限范围。

“暂停自动推进”只暂停后续对话步骤，已经提交的下载和处理继续在后台运行。“继续任务”恢复保存的推进状态。要取消或重试某项真实任务，可以在同一对话里明确提出取消或重试；软件检查最新用户请求、任务归属和已有任务状态。不会在自动完成通知中自行重试。取消不会删除已完成文件。

范围可以来自当前地图、用户提供的参数，或 `geod_place_search` 返回的实际地点范围。明确指定的地点优先于当前地图；例如地图在旧金山时，“下载纽约最新卫星影像”会先定位纽约市，不要求用户移动地图或填写坐标。服务没有返回范围、多个地点确实无法区分时，才需要补充信息。Agent 不猜测坐标，不能绕过数据源权限、格式或原生处理限制。

“最新卫星影像”未指定来源、产品或日期时，使用原生 UTC 当前日期、最近 30 天、Earth Search Sentinel-2 L2A 真彩色和按观测日期倒序检索；会简短说明默认条件并继续检索。保留全部云量，避免把“最新”悄悄改成“少云”；回复实际日期与云量。无结果时可扩大到 90 天、365 天。明确的用户条件始终优先；目录相交不代表完整覆盖。下载需求在同一轮生成实际文件预检后的方案，是否执行仍由原生会话权限决定。

地点工具调用固定的 [Photon API](https://github.com/komoot/photon/blob/master/docs/api-v1.md)，仅查询用户指定的地点；城市模式过滤建筑和兴趣点，校验并转换服务的边界框顺序。地点结果注明 OpenStreetMap 来源与 ODbL，持久缓存七天；查询串、结果数量、响应大小、请求频率和存储数量均有限制。返回的是检索矩形，不是行政区多边形。开发版使用 Photon 公共演示服务，按其[使用说明](https://github.com/komoot/photon)控制请求量；正式大规模使用需评估独立服务部署。没有引入兄弟仓库的运行时依赖。

工具集更新时，同一模型连接的旧对话会自动恢复，保留应用对话 ID、显示历史、方案和任务引用，以及原生保存的权限。下一条消息使用当前工具集建立新的 Codex 执行上下文，并带入有长度限制的历史摘要；旧回复中的能力说明按历史内容处理。不同账号、接口、协议或模型的历史不会自动迁移到当前连接。

[地点检索验收](../prototype/qa/agent-place-verification.json)：一条“我要下载纽约最新的卫星影像”，地图仍在旧金山，通过自有测试模型实际调用地点服务、Earth Search 目录和文件大小预检，生成纽约市 2026-10-03 的四景真彩色待确认下载方案，预计 786,204,567 字节。没有提供坐标，没有创建下载任务。另在无模型的原生验收中确认地点缓存跨重启命中。目录相交没有被当作完整覆盖证明，回复长度单独受验收限制。权限、上下文、会话、界面与隔离检查通过；这项验收没有修改用户连接或制作安装包。

## 执行与恢复

- 原生 `execution-policy.json` 保存会话权限，绑定模型连接。模型没有修改权限的工具。工具升级保留同一应用对话的原生权限，不从历史文本授予权限；未知会话或连接不符不能继承已有对话的自动执行许可。
- `geod_plan_execute` 使用现有方案 ID、哈希、来源校验、有效期、文件检查和幂等提交；提交只代表建工程或排队，不代表文件完成。
- `geod_job_control` 仅处理本对话方案的真实任务。新的用户请求提供临时权限，每个任务动作每条消息只允许一次。恢复进程和后台通知不提供这项临时权限。
- 本地监视器读取原生任务状态，等待 `settled=true`；运行期间不请求模型。任务结束后恢复原来的 Codex 会话，让模型检查文件并完成原需求中的剩余步骤。矢量遵循其独立的已提交且文件已校验规则。
- 失败通知中的后续执行在原生入口被禁止，保持只读检查，等用户提出新的处理要求。停止回复会暂停自动推进，保留已经提交的任务记录。
- 切换对话不会抢走当前界面。保存的完成通知会在回到对应对话后继续处理；退出软件时暂停推进，下次可明确继续。托盘运行保留现有后台任务和 Agent 进程。
- 每轮最多 20 次业务工具调用、24 次模型请求；每次明确继续允许最多 8 次后台续接。这些用于阻止重复执行和费用失控，不限制界面动效。
- `geod_workspace_open` 只能打开校验过的本机栅格或矢量 ID。由应用工作区执行显示并确认接收；模型不能传入文件路径、任意 URL 或操作用户桌面。显示请求不等同于已观察到地图像素。

开发验证分开记录：权限与状态单元测试、界面交互测试、隐藏浏览器视觉检查，以及隔离目录中的真实模型、目录、下载和裁剪。仅在真实流程通过后更新验收记录。本次不制作安装包，不发布或修改 GitHub Release。

[旧对话恢复与加载验收](../prototype/qa/agent-conversation-restore-verification.json)：在同机隔离目录中，首次读取历史从 5,460 毫秒降至 382 毫秒，完整运行文件校验从 5,370 毫秒降至 234 毫秒，已启动服务的读取均不足 1 毫秒。开发配置仅优化 SHA-256 依赖，原生校验改为后台线程分块读取；没有跳过校验，也没有额外调用模型来读取历史。真实模型验收先建立旧工具集对话，再升级工具并在同一个应用对话继续纽约需求，实际检索后生成待确认方案，未创建下载任务。模型恢复上下文最多 48,000 字节，保留原始请求及最近完整记录；完整显示历史不截断，已保存附件会重新验证后传入。

输入框移植后的 Agent 面板 52 项组件测试与共享 UI 12 项测试通过。隐藏浏览器使用产品样式验证 260、320、460、493 像素面板：初始窄面板、空文本、长文本、再次缩放时高度正常，工具栏中心对齐且不重叠；附件图标、原生权限请求、未知／已报告用量、模型管理、输入法与既有流式阅读交互通过。另复核连接测试弹窗。界面验收的业务执行和付费模型请求均为零。

## 已保存的真实流程验收

[验收记录](../prototype/qa/agent-conversation-verification.json)：通过自有 `deepseek-v4-flash` 测试通道，一条中文需求、零次方案卡片点击，完成真实 Earth Search 检索、新建工程、1,958,612 字节 SCL 原文件下载、46 × 56 原生网格裁剪、成果校验和校验后的工作区显示请求。下载与裁剪均成功，保存了两项真实任务及各自的 SHA-256。后台自动续接一次，合计 15 次模型请求。测试未修改用户模型连接或密钥，未操作用户桌面；实际 Windows WebView 中的地图像素不在这条隔离原生验收里。
