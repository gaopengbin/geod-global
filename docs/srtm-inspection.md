# NASA SRTMGL1 v003 接入与验收边界

2026-10-02。探索页新增「NASA Earthdata · SRTM」，固定使用 CMR-STAC `SRTMGL1_003`，没有把 NASADEM、SRTMGL3、NUM 或在线地形图当作 SRTMGL1 原文件。实时目录、公开浏览预览和授权入口可用；HGT ZIP 下载适配、本地读取和缓存已实现，尚未使用真实账号下载生产原包。

## 产品与文件

SRTMGL1 v003 为 1 角秒产品，覆盖主要陆地范围为南纬 56° 至北纬 60°。每个 1° 瓦片为 3601 × 3601 个采样点，相邻瓦片共享边缘行 / 列；HGT 使用无内嵌空间元数据的大端有符号 Int16，原始高程单位为米。文件名给出西南角，左上采样点为 `(lon, lat + 1)`，间距 `1/3600°`，Point 网格外边界扩展半个像元。格式依据 [LP DAAC SRTM 用户指南](https://lpdaac.usgs.gov/documents/179/SRTM_User_Guide_V3.pdf)，独立解码使用 [GDAL SRTMHGT 驱动](https://gdal.org/en/stable/drivers/raster/srtmhgt.html)。

水平参考 WGS84 / EPSG:4326，垂直参考 EGM96 / EPSG:5773；不套用 GLO-30 的 EGM2008、Float32 或 3600 列参数。[USGS 高程参考说明](https://doi.org/10.5066/F7PR7TFT)。预览将有效高程按采样的 2–98 百分位映射为灰度，遇到 `-32768` 则透明；科学取值返回原始 Int16，有效的 0 和负高程不会作为 NoData。版本 3 的空洞填补由提供方完成，GeoD 不生成缺失高度，也不评估地形精度。

## 软件入口与授权

按区域实时检索，列表显示短瓦片名、版本与高程基准，保留官方元数据与浏览预览。没有光学云量 / 逐景采集日期筛选或时间轴。选中瓦片后可以进入带工程名的下载确认，来源和原包链接随工程持久化；恢复工程仍识别为 SRTM。

下载前复用「设置 → 数据源账号 → NASA Earthdata」和已有的 Windows 凭据管理器授权。用户在官方 Earthdata Login 管理令牌，并按提供方要求允许 LP DAAC 应用访问；验证令牌有效不能替代产品访问验证。未授权时确认页提供管理授权入口，阻止启动下载；直接调用原生任务也会失败，且无输出文件。

原生 worker 重新核对当前 CMR `SRTMGL1_003` 条目及准确的 HGT URL，仅接受审核的 LP DAAC 同对象 CDN 跳转，跳转不携带 bearer。工程、任务和来源保存稳定无签名原包 URL。归档上限为 64 MiB，当前接受一个不加密、不含符号链接的 HGT 条目，文件名须匹配瓦片、长度为 25,934,402 字节，ZIP CRC 与 SHA-256 均需通过；没有解压到用户指定的文件系统路径。该归档约束依据文档和合成文件，仍须生产原包验收。

本地工作空间可显示灰度图、读取原始高程、查看 EGM96、下载来源和哈希。工程文件的小图使用受管磁盘缓存，重启复用。SRTM 工程裁剪与拼接已接入，保留 Int16、EGM96 和共享边缘 Point 网格，并使用明确标注的合成原包在真实运行时及独立 GDAL 验证；见[处理规则与证据](srtm-processing.md)。重投影和地形分析尚未接入。

## 证据与范围

- 实时浏览器以小区域 `[-122.55,37.68,-122.32,37.84]` 检索官方目录，返回 `N37W123.SRTMGL1.hgt`，随后沿官方 cursor 取到空末页；公开浏览 JPEG 完整解码为 3601 × 3601。没有账号或原文件传输，预览不是科学高程文件。
- 真实隔离运行时的另一个瓦片 `N38W123.SRTMGL1.hgt` 未授权任务失败，字节为 0、输出为空，提示在设置中连接数据源。
