# 本地文件缩略图缓存

文件列表与工程文件卡片的缩略图由同一运行时接口提供，适用于已完成的本地 SCL、RGB、反射率、原始及工程处理后的 Landsat QA_PIXEL / QA_RADSAT、NAIP、GLO-30 高程 GeoTIFF、SRTMGL1 HGT ZIP 及支持的拼接成果。页面仍保留最多 64 张小图的内存缓存；运行时另将最长边 160 像素的 PNG 以带校验值的 JSON 条目持久化到工作空间的 `cache/thumbnails/v1/`，重启软件或刷新页面后继续复用。

缓存键包含任务 ID、源 SHA-256、数据类型、缩略图尺寸及预览版本。首次生成继续检查源文件受管路径、字节数与完整 SHA-256。命中时只检查受管文件身份、记录大小、修改时间与创建时间，再验证缓存 PNG 的尺寸、格式及校验值，不重新读取整个原文件。源文件缺失、路径或文件信息变化、校验值变化、预览版本变化均不会使用旧缓存；生成期间源文件变化也不会提交缓存。

缓存写入使用同目录唯一临时文件、同步与原子替换。损坏、超长、旧版条目自动重新生成；缓存目录无法写入时仍返回成功生成的缩略图。重启后的首次访问、每次命中与写入都会检查容量，最多保留 64 MiB、1024 个条目，优先清理最久未使用的小图和中断写入的临时缓存。回收只处理此缓存目录内的受管条目，不删除影像源文件或处理成果。

缓存只用于导航预览，不代替原始影像完整性检查；栅格检查、像元查询及拼接处理仍执行各自的源校验流程。界面点击重试会在没有有效内存预览时再次请求运行时；无需用户手动管理缓存文件。

切换页面或多个窗口同时打开文件列表时，上一页的预览任务可能仍占用原生工作线程。文件卡片对此暂时忙碌状态最多自动等待一分钟，期间保持加载动效；按共享队列重试，避免后续小图成批显示失败。断连会停止重试，文件缺失、校验失败及其他错误不自动重试。实际 Landsat 验收用真实冷文件占用工作线程，收到 17 次忙碌响应后小图正确显示，见下方对应记录。

受控测试覆盖进程重建后复用、时间与 SHA-256 失效、源文件缺失/篡改/路径越界、生成期间变化、损坏 PNG/JSON/超长/旧版缓存、自主容量回收与缓存不可用回退。真实文件首次、再次和重启后的对照可用 [verify-thumbnail-cache.py](../scripts/verify-thumbnail-cache.py) 复现，记录见 [thumbnail-cache-verification.json](../prototype/qa/thumbnail-cache-verification.json)。

本机真实拼接成果的小图首次生成约 15.6 秒，重新启动运行时后约 15 毫秒返回；SCL 与真彩色源文件重启后分别约 16 和 47 毫秒。三张缓存合计 147,074 字节，重启前后 PNG 完全一致；这些是本机单次验收数据。92 个运行时测试与无警告 Clippy 检查通过。
