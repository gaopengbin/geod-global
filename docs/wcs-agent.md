# WCS 软件内 Agent 接入

WCS Agent 已接入现有原生覆盖数据流程。它下载服务按区域生成的栅格，不把结果标成整景原文件。协议、坐标系、预算和验证规则沿用 [WCS 区域栅格](wcs-coverages.md)，架构沿用 [软件内 Agent](agent.md)。

## 操作链路

用户先在软件中连接服务。模型只能读取已保存的连接和数据集，不能新增服务、传入下载 URL、写凭据或批准执行。

1. `geod_wcs_connections` / `geod_wcs_coverages` 分页读取真实连接与数据集身份。
2. `geod_wcs_describe` 读取覆盖定义，`geod_wcs_prepare` 根据用户明确指定的 WGS84 范围计算原生网格请求。此时只保存定义和计划，没有工程或栅格文件。
3. `geod_wcs_project_plan` 生成工程审查卡。用户可以修改名称、区域和选择；范围修改重新派生网格计划，旧审查不能再执行。确认后仅保存工程信息。
4. `geod_wcs_download_plan` 检查工程成员和已有任务，只审核尚未下载的请求。确认后立即返回原生任务 ID，传输及逐块验证在共享任务队列完成。
5. `geod_plan_status` 核查实际状态和任务收尾，`geod_wcs_inspect` / `geod_wcs_pixel` 校验文件并读取原值。结果仍在正常工程、“任务”、“我的数据”和工作空间中使用。

确认卡展示原生网格尺寸和实际对齐范围；服务生成文件的编码大小在返回前未知，不显示猜测字节数。单文件沿用 512 MiB 上限，不自动缩小区域或降低分辨率。字段单位与空值来自原始覆盖定义，不能因为名称像水深就改成米；实际 TIFF 标签另外核对。边缘向外对齐原生像元并与数据覆盖取交集，不做重采样或多边形遮罩。

## 保存与恢复

审查绑定会话、计划身份、内容哈希、有效期和完整工程范围。原生确认将批准记录与工程或排队任务写入同一次原子提交；保存失败不会留下获准的幽灵任务。任务 ID 由审查身份派生，重复确认和重新启动不会重复下载。

追加工程保留已有场景、自定义 STAC 文件、WCS 请求和区域。工程在审查后发生变化时拒绝旧确认。下载前仍核对服务能力和覆盖定义，文件返回后沿用原生 WCS 全部主图样本、网格、通道和空值校验。复用完成任务前重新检查受管路径、完整字节数及 SHA-256；损坏记录与替代任务一起提交，并保留失败原因。

Windows 原生工具分派器使用有界调用帧，避免不断扩大的工具表让异步调用链占满线程栈。这修复了公开请求验收中暴露的栈溢出；没有通过扩大测试线程栈掩盖问题。

## 验证范围

2026-10-05 的全新隔离目录完成原生工具入口、工程修订、单独确认、实际下载、重启恢复和文件复用。明确指定的公开样例为 EMODnet `emodnet__mean`、经度 2–2.05 / 纬度 53–53.05：48 × 48 单通道、9,600 字节，SHA-256 `0562d00271b191f277e79b6140dad31fe7d1b55ad5ddb4dc24c4f252f7d1eadb`。独立 XML 网格解释与 Rasterio 核对全部 2,304 个样本及掩膜；第二次独立公开请求返回相同字节。验收输入保存在 `scripts/acceptance/wcs-public.json`，它不是软件默认连接。

此服务对 `Depth` 声明的单位为 `W.m-2.Sr-1`，实际文件没有单位标签；仍保留两者，不推测校准或单位。验收针对该小区域及当前支持的 WCS 2.0.1 规则网格流程，不证明全部服务、任意体量或数据许可可用。

原生边界与实际文件验证、隐藏浏览器的界面契约检查、模型往返和安装版窗口验收分别记录，不互相替代。新增工具需要新会话；已有会话历史保留，工具集合变化时不会强行继续旧模型线程。

实际模型验收使用已有 `deepseek-v4-flash` 中转路线，完成四轮真实对话、14 次原生模型工具调用及一次原生参数修订：查询连接与覆盖定义、准备网格与工程审查、原生修改及确认后生成独立下载审查、下载后读取状态与原始像元、进程关闭后恢复同一会话和模型线程并重新校验。一个工程、一个实际下载任务；修改后的旧计划和错误哈希均拒绝，重复确认不新增任务，已完成文件校验后复用。原生审查与模型不可达的确认入口分别调用，未操作用户桌面或写入凭据库。

该模型流程生成的真实文件另经独立 XML 网格解释、Rasterio 全部样本 / 掩膜、原生读取和第二次公开 GetCoverage 逐字节比对。结果仍为上面的 48 × 48 文件，登记记录没有被只读验收改写。48 个动态工具中，29 个只读，19 个上下文、来源、检索、元数据与审查工具；模型仍没有批准或直接下载入口。其他模型与安装版窗口尚需各自验收。

真实数据和模型结果索引见 [WCS Agent 验收记录](../prototype/qa/agent-wcs-verification.json)。隐藏浏览器的中英文、浅 / 深色与两种宽度采用明确的界面契约数据，不能拿来证明原生执行或模型可用性。
