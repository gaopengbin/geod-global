# 原文件下载的超时与恢复

2026-10-04。下载客户端不再以 30 分钟总时长终止正常传输。接近 2 GB 的 RTC 原文件在慢网络上可能超过这个时长；只要仍在接收数据，任务可以继续运行。

连接建立仍有 20 秒限制。每次网络读取在成功接收数据后重新开始计算 45 秒等待时间，下载 worker 同时检查连续 45 秒无数据的情况。目录、令牌及账号请求保留各自较短的限制。用户取消、退出、来源拒绝、传输超限和文件校验失败仍会结束任务。代理模式保持跟随系统、直连和手动配置三个选项；新设置作用于新请求，已经打开的响应继续使用原来的连接。

已审核的公开原文件下载现在支持有条件的字节续传。任务中断后保留已同步到磁盘的数据和校验记录；重新打开软件仍将任务标为“已中断”，由用户明确重试同一任务。重试前重新计算已保存部分的 SHA-256，核对任务、来源、资产、总长度和强 ETag，随后发送 Range / If-Range。只有来源返回相同强 ETag、准确起始位置与总长度的 206 响应，才显示“已续传”。保存了临时数据或点击了重试，都不等于续传已经成功。

来源忽略 Range、版本变化、返回不匹配的分段或 412 / 416 时，丢弃旧部分并从头获取完整响应；不会把两个版本拼成一个文件。403 等授权拒绝保留有效的待恢复数据并报告失败，不能绕过授权或自动反复重试。用户主动取消会清除临时文件和恢复记录；正常退出及意外结束可保留有效记录。恢复记录不包含明文下载地址、临时 SAS 或账号凭据。Range / If-Range 的版本条件来自 HTTP 标准。[RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html#name-if-range)

当前恢复范围是已审核的普通公开原文件，包括 Earth Search 和 Planetary Computer 分发的 COG。NASA Earthdata / Copernicus 受保护原文件、自定义 STAC 与服务器生成的 WCS 响应仍从头重试；工程拼接、裁剪等本地处理也从头运行。账号授权入口已经接入，但 NASA / Copernicus 的成功授权及生产原件仍待真实账号验收。瓦片包等独立获取流程不由这一恢复实现覆盖。

下载并发仍最多两个文件，没有带宽限速。原文件必须完整接收，通过总长度、文件签名、完整 SHA-256 及适用的来源检查，才能记为成功；未完成部分不会显示为可用文件。文件 SHA-256 用于传输完整性记录，不等于供应商真实性或科学精度认证。进度查询只观察原任务，不因观察时间用完而结束下载或创建重复任务。

2026-10-04 的自动检查：原生库 444 项、CLI 4 项、桌面 4 项、前端 201 项通过；另有 4 项需要外部条件的原生测试未运行。12 项恢复测试使用私有 HTTP 协议夹具，覆盖精确续传、关闭 / 重开、版本变化、拒绝授权、局部文件损坏、主动取消和临时文件清理；这些夹具不是生产影像。实际 Sentinel-1 VH 测试在受控结束私有进程后，恢复同一个任务的 4,374,528 字节已校验前缀，并用独立请求逐字节核对跨续传位置的 64 KiB。约 1.84 GB 的完整原件还在下载，此项证据证明恢复行为，不代表该完整原件或 VH / HH / HV 工程处理已验收。

生产前端在 1440 像素英文亮色和 1024 像素中文暗色下，通过实际原生任务、桌面 CSP、状态说明、卡片高度及动画结束后的截图核对；六个任务的 VH / HH / HV 标识与原生任务逐项对应。使用无界面浏览器，未操作用户桌面，也未提交真实账号授权。桌面开发程序已更新，未生成安装包或发布。[本轮恢复记录](../prototype/qa/source-transfer-resume-verification.json)；[此前超时策略记录](../prototype/qa/source-transfer-policy-verification.json)保留当时尚未实现续传的状态。
