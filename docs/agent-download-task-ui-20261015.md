# Agent 下载任务展示精简（2026-10-15）

同一轮用户请求中的已提交下载方案现在合并为一个紧凑的下载任务区。该区域只展示总状态、真实传输字节数、已就绪文件数和必要的失败入口；下载明细默认收起。展开明细后是每个方案一行的紧凑列表，一次只展开一项完整详情。

该分组从已有方案引用和本地任务回执投影得到，不改变原方案、哈希、审批、下载、重试或权限检查。不同用户请求不会合并，重复引用的方案和同一原件任务不会重复累计。

待确认方案继续保留确认按钮。失败或中断时显示简短提示和查看任务入口；主动取消不伪装成成功，也不显示失败警告。未知总大小不展示完整总量或虚构百分比，收到全部字节但尚未完成本地结算时仍保持未完成状态。

执行过程现在可在运行中手动收起。下载任务摘要位于过程详情之外，收起过程不重置下载明细状态。全部下载完成并有最终回复后，下载记录随执行过程收起；右侧成果中的“查看成果任务”可重新定位并展开对应方案。
