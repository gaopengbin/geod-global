# Maxar / Vantor Open Data candidate — 2026-10-12

One standalone item's native analytic original, preview, raw samples and reopened project are now verified. The channel remains **planned**: there is no event-aware built-in preset or original-dropdown entry, and this is not full-platform validation.

The [AWS registry](https://registry.opendata.aws/maxar-open-data/) lists the public `maxar-opendata` bucket in `us-west-2`, high-resolution disaster-event ARD imagery and CC BY-NC 4.0. The [publisher's current asset guide](https://xpress-docs.maxar.com/OpenData/OpenData_viewing.htm) distinguishes minimally processed multispectral/panchromatic imagery from an 8-bit visual display product. Neither document promises global on-demand coverage.

Anonymous requests succeeded for the actual catalog, the `Cyclone-Ditwah-Sri-Lanka-Nov-2025` event, an acquisition collection and its first published item. The unchanged event collection says `CC-BY-NC-4.0`, but the acquisition collection says `proprietary`. This conflict remains explicit; no original document or license field was rewritten.

One complete published visual file was independently downloaded: `102001011D2F3500-visual.tif`, dated **2025-12-05**, 24,418,178 bytes in 3.969 seconds, SHA-256 `e5a08af5b5b7407336f26c6255f884bfd46b935e6acd5e53a8f739963b695dd9`. Rasterio decoded all 303,038,464 samples of its 17,408 × 17,408, single-band UInt8 EPSG:32644 grid. This asset is **panchromatic visual**, not RGB or original calibrated reflectance. Its 0.30517578125 m output grid differs from the item's declared sensor GSD 0.79 m; resampled grid spacing is not a claim of equivalent independent spatial detail.

The earlier frozen runtime (`df0c681841690af165bc8956058b1bca00d349d10b2374e5fbb932193b45ec63`) refused this item before creating any project or download because S3 declares `Content-Type: binary/octet-stream`. That historical failure remains in the JSON receipt. The newer frozen runtime (`32a0af3544b9ad7451ba267613f2bbb6990a6292d42a821f10252e9e449ef04d`) accepts a bounded, complete UTF-8 body only after validating its STAC JSON structure. It connected the unchanged item and acquisition collection; their recorded hashes remain `2a09468afa2c568fd6f52e074ab45fb69f06d854588d781f6444a588d2064fc5` and `a1a2145f171bb0922a5d1ef82df7e64edba26929fb74117d815284a63ab61c2f`.

The actual `pan_analytic` selection produced one settled fresh native download of `102001011D2F3500-pan.tif`: **41,366,369 bytes**, SHA-256 `8f5fe0f05e5b0f2ddb09c4499508522973e1ebd37425c8d0e5bb169bf38867e6`. The original is single-band UInt16, 7,493 × 7,493, EPSG:32644, with a 0.7089950620579207 m grid. Independent Rasterio decoded all **56,145,049** samples; five native raw samples matched it: `(0,0)=0`, `(3746,3746)=245`, `(2497,2497)=0`, `(4995,4995)=780`, `(7492,7492)=502`. Native inspection generated a 768 × 768 grayscale preview. A restarted private runtime reopened the unchanged snapshot, saved project and original inspection hash. The final inspection rerun reused this settled original; it was not a second download. No RGB, reflectance calibration, COG conformance, crop or valid-AOI coverage is inferred.

The original has a **per-dataset validity mask** but no scalar TIFF NoData value. Rasterio's mask marks 24,511,763 pixels valid (43.66% of the full file); this is a file-mask count, not an AOI coverage or cloud-quality result. The current native preview/pixel tools retain the complete original mask in the file but do not apply it: they report scalar-tag `noData=false` for all five samples. At `(0,0)` and `(2497,2497)` GDAL's dataset mask says invalid even though scalar-tag NoData is false. These are different validity definitions, so zero samples must not be presented as useful valid imagery on that native flag alone. The GeoPackage `data-mask` asset is also preserved in the source metadata but remains unsupported by this raster download path.

The event's **CC BY-NC 4.0** versus acquisition collection's **proprietary** declarations remain unresolved and visible; native accessibility does not establish commercial-use permission. Before promotion, implement event/date/area selection in the original dropdown, retain this license conflict and explain/apply file validity masks in result handling.

Private raw documents, both complete originals, byte hashes, preview and historical/new native receipts remain under `.verification/maxar-candidate-20261012/`; the companion JSON records their evidence hashes.
