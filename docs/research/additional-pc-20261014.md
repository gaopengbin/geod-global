## Scientific values and license boundaries

[NOAA's OISST description](https://www.ncei.noaa.gov/products/optimum-interpolation-sst) defines a daily 0.25° L4 blended, bias-adjusted and interpolated analysis using satellite and in-situ observations. The exact 2020-09-01 Item interval is 00:00:00Z–23:59:59Z. Stored Int16 DN and TIFF scale 1/offset 0 remain unchanged; publisher STAC declares Celsius scale `0.009999999776482582`. Valid zero and negative SST DN are preserved, and -999 alone is scalar NoData. A filled analysis field is not a direct observation at every pixel, an unprocessed AVHRR scene or a local coastal-accuracy guarantee.

Both Collections declare `license=proprietary`; preserve those original fields. The linked [NOAA CDR Use Agreement](https://www.ncei.noaa.gov/pub/data/sds/cdr/CDRs/Sea_Surface_Temperature_Optimum_Interpolation/UseAgreement_01B-09.pdf) states the CDR data are publicly available without use restrictions and requests scientific acknowledgement/citation. The product definition retains that explanation alongside the Collection field rather than inventing a Creative Commons license. Cite the exact OISST v2.1 release and Huang et al. (2021), doi:10.1175/JCLI-D-20-0166.1.

The [NASA MCD64A1 file specification](https://ladsweb.modaps.eosdis.nasa.gov/filespec/MODIS/61/MCD64A1) defines ordinal burn date, 0 unburned, -1 missing and -2 water. Thus raw -2 is **not** scalar NoData and valid unburned 0 must remain visible. QA is separate: bit 0 land/water, bit 1 data validity, bit 2 shortened mapping period, bit 3 contextual relabeling, bits 5–7 special conditions for unburned cells. The original TIFF embeds the QA legend. The software exposes original values/flags, not inferred fire severity, probability, emissions or independent event confirmation. No new combined quality mask replaces either original.

MCD64A1's radius is `6371007.181 m`; real spacing is `[463.3127165283333,463.3127165279167] m`, with top-left `[10007554.677014,4447802.078664]`. The source declares a custom sinusoidal sphere, not an EPSG:4326 raster. The UTC observation interval is 2020-09-01 through 2020-09-30; creation/processing 2021-11-05 and Blob Last-Modified 2022-04-02 are kept separate. The current Collection links the [LP DAAC policy page](https://lpdaac.usgs.gov/data/data-citation-and-policies/), which returned HTTP 403 in this review. NASA's general policy has default open-data guidance, but it is not silently substituted for this Collection's original `proprietary` field or called a separately verified specific license. Retain Giglio et al. (2021), doi:10.5067/MODIS/MCD64A1.061, NASA/LP DAAC/USGS EROS and Microsoft distribution attribution.

## Independent code review and bounded fixes

The review found that MCD source selection used only the publisher WGS84 bbox. AOI `[104,39,104.1,39.1]` passed that predicate although its sinusoidal x coordinates are wholly west of the original grid. The finite adapter now additionally solves continuous positive-area intersection against the independently verified 2400 × 2400 affine extent and original sphere. It clips the latitude span and solves longitude overlap through `cos(latitude)`; it does not mistake an AOI's projected bbox for actual overlap or rely on corners alone. Publisher Item geometry/bbox and original bytes are unchanged. Meaningful regressions cover the independently transformed day-252 AOI, a large AOI containing the tile, three bbox-inside/grid-outside counterexamples and a touching-only edge. Grid intersection still makes no promise that the selected area has valid data or a mapped burn.

The review also found that these publisher assets declare no `file:size`/checksum, so the general transfer checker did not enforce the separately captured complete-file references. The dedicated `validate_original(proof,url,bytes,sha256)` now binds each selected canonical layer to its exact original length/SHA without adding fields to publisher metadata. Cross-layer replacement, including Burn_Date's path returning the reviewed QA bytes, is rejected even though both files have valid original MODIS grids. The parent connected this policy to shared transfer verification and its local reopen path. After both fixes, all five dedicated native contract tests passed; the explicit complete-independent-original regression also passed again (1 test, 1.57 seconds), preserving all three original hashes/grids and 18 raw/NoData references. A separate independent reviewer confirmed the bounded fixes and checked the continuous intersection against an inverse-acos oracle for 10,004 deterministic local AOIs, with no disagreements.
