# 下载与预览恢复实测：2026-10-26

## 排查范围

从本机及其测试环境的已登记匿名标识排除后，本轮关注 6 条生产失败事件：Planetary Landsat 原文件传输失败 2 次；Earth Search 瓦片预览失败 3 次；Planetary Landsat 瓦片预览超时 1 次。

事件没有影像编号、精确范围、原始异常或签名链接，不能逐条重放原用户请求。下面是用同类真实渠道和主动故障复现得到的修复，不能说成已证实的全部历史根因。没有补写或删除历史生产事件。

## 修复

- 已核验的内置公开 COG 下载遇到连接中断、读取超时或临时 HTTP 错误，最多自动重试两次。有已下载前缀时，仅在存在绑定当前任务的有效断点记录时续传；继续校验原版本、ETag、Content-Range 和保存字节。403、404、取消和校验失败不自动重试。自定义 STAC、覆盖服务、需账号及生成式原件接口保留各自协议。
- 原先 reqwest 的外层异常会变成泛化的正文读取错误。现在保留固定的超时、连接失败、响应不完整分类，作业记录增加兼容旧记录的 `networkRetries`，失败埋点读取实际自动重试次数，不用用户手动重试次数代替。
- 实际 geotiff 阻塞读取会把原始 503 异常丢掉，改成只包含 undefined 块的 `Request failed`。共享 COG 源现在保留本来源生命周期内的最终传输原因，将 HTTP 状态、阶段和重试次数交给元数据及瓦片失败记录。
- 预览单次读取仍允许 30 秒，增加总共 42 秒内的有限超时恢复机会，早于地图 45 秒静默兜底。用户取消、切源、销毁或地图已失败时终止剩余读取。
- 对可见的 Content-Range 核对偏移和长度；实测公开 S3 桶未向浏览器 CORS 开放该响应头，因此不将不可见的头误判为无效响应。继续拒绝忽略 Range 的整文件 200 响应，不用全量下载掩盖预览失败。

所有新增遥测仍只含固定诊断码，不上传原始异常、文件路径、精确区域、签名 URL 或聊天内容。

## 真实链路验证

使用本仓库构建的原生服务、独立存储 `.verification/reliability-20261026/store`、隔离 Edge 验收页面和真实公开数据；未读取用户工作空间。页面操作包括区域检索、选择、预览、下载确认、打开工程、打开本地成果和原始像元检查。不是以测试 TIFF 或模拟下载替代原件。

| 链路 | 原件与结果 |
| --- | --- |
| Planetary Landsat | `LC08_L2SP_044034_20261013_02_T1`，B4/B3/B2 三原件共 247,566,500 字节；下载、整文件哈希、逐块解码和本地 RGB 成功 |
| 真实传输中断 | `LC09_L2SP_044034_20261005_02_T1` 红波段；测试代理保持原供应商 TLS 验证，在接收约 5 MiB 时主动断开一次；自动从 5,210,112 个已验证字节续传，最终 95,194,940 字节、一次自动重试，无人工重试 |
| Earth Search | `S2B_10SEG_20261015_0_L2A` 真彩色预览成功；另实际下载 1,943,955 字节 SCL，完整解码、本地分类图和像元读取成功 |
| 瓦片 503 恢复 | 对真实 Earth Search 影像请求注入持续 503；及时显示失败，记录 `preview_tile/upstream_unavailable/503/retries=2`；移除故障、点击重试后重新显示真实源像素 |

独立 rasterio/GDAL 读取每个全分辨率块，并核对字节数、SHA-256、CRS、类型、像元大小及有效数据。应用工作空间实际取样与独立读值一致：Landsat RGB 为 9052/9345/8231；GLO-30 样点为 0 米；SCL 为 4。0 米是有效值，没有当成缺失数据。
