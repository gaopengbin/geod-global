# 静态 STAC 目录

“自定义栅格来源”新增“静态 STAC 目录”类型，桌面、本地 HTTP 和 CLI 共用原生实现。它递归发现公开 Catalog / Collection 的 `child` 链接，保存原始文档，再读取所选目录及子目录的 `item` 链接。保留 Item 的真实标识、Collection 标识、资产、属性、几何、时间和许可声明；目录选择使用本地 URL 哈希，不把分组名称伪造成 Collection ID。

实现参考 [STAC 1.1 Catalog 规范](https://github.com/radiantearth/stac-spec/blob/v1.1.0/catalog-spec/catalog-spec.md)与 [Item 规范](https://github.com/radiantearth/stac-spec/blob/v1.1.0/item-spec/item-spec.md)。静态目录没有服务端 Item Search 能力，本地按声明的二维 WGS84 边界框相交及观测时间相交筛选；这不是 STAC API 的精确几何相交查询。没有边界框的条目不计入结果；启用日期筛选时，没有可用观测时间的条目不计入结果。输入区域仍使用现有不跨日期变更线的二维范围规则。

## 范围与恢复

- 连接时最多发现 128 个目录、24 层子目录、20 MiB 元数据；单个文档最多 8 MiB、4096 个链接。超限会拒绝连接并要求缩小入口，不能保存半个目录树作为完整发现结果。
- 单次搜索最多安排 10000 个唯一 Item 地址；每页最多扫描 32 个 Item 文档，最多返回用户请求的 1–100 个结果。一个查询最多扫描 1000 个 Item 文档和读取 20 MiB 元数据。无匹配结果的一页仍可继续扫描；达到上限与扫描完成分别展示。
- 扫描进度中的计数是已读取的 Item 文档数，含不匹配的条目；它不是供应商声明的总匹配数。区域或时间变小可以减少结果，但仍可能需要读完整所选目录的 Item 文档，因此超限应优先选择更小的目录分组。
- 只跟随 `child` / `item`，不沿 `parent` / `root` 回爬；相对地址按各自文档地址解析。循环及一个子目录的多个父目录明确拒绝，避免所选分支缺失内容。不同 Catalog 可声明相同 ID，但不同地址重复的 Collection ID 或 Item 身份会拒绝。
- 元数据须为同一公开 HTTPS 来源、GET 请求，不跟随重定向，不携带账号、临时签名或自定义请求头。原文件仍可位于其他公开 HTTPS 主机。Collection 声明可以来自条目自身指向的同源 `collection` 链接，不必位于当前目录的祖先路径。
- 搜索游标绑定当前连接和全部筛选条件；使用后不能重复消费。重新连接或移除来源会使游标失效；软件重启后需重新开始搜索。已保存的工程选项和来源快照保留，离线恢复会逐个校验原始文档内容哈希及 `child` / `item` 路径，不依赖当前连接仍存在。

下载继续使用[自定义栅格来源的工程和任务规则](custom-stac.md)，传输前重新读取真实 Item 并核对资产声明。512 MiB 原文件上限、无字节续传及通用科学处理限制没有在这个增量中扩大。目录搜索、资产选择、工程与原文件任务已增加 [MCP 接口与独立验收](stac-mcp.md)；软件内 Agent 的自定义工程 / 下载审核计划也已接入，必须分别确认卡片。

## 接口

连接请求使用 `kind: "catalog"`。响应的 `catalogNodes` 提供真实目录的 `id`、`kind`、标题、地址、父节点及本地 `key`。查询仍使用已有 `stac search` / `/stac/search`，其中 `collectionId` 为所选目录的 `key`；结果的 Item `collectionId` 保持上游的真实值，`provenance.searchMode: "catalog"` 表示本地目录筛选。响应额外提供累计 `scannedItems`，原 API / Item / TIFF 响应和旧注册记录继续兼容。

## 2026-10-05 验证

真实公开请求使用 Capella Open Data 的 2022 年 11 月静态入口，递归读取 7 个目录。选择 11 月 13 日分组后，按爱尔兰区域及 2022 年 11 月日期完成 2 页、4 个 Item 文档的扫描和匹配。独立脚本逐个核对原始文档哈希、真实标识、相对链接、边界框与时间筛选、原生工程引用、错误筛选游标拒绝、已消费游标拒绝；移除连接及停止自有服务后，独立 CLI 离线恢复同一已保存快照。

证据：`.verification/stac-static-20261005-c/acceptance.json`。这一轮是**真实目录、筛选和工程保存验收**，没有下载 Capella 原文件，也没有声称 SAR 科学校准或原生桌面窗口验收。该目录的 Collection 许可声明为 `proprietary`，按原文保留；公开可请求不代表已获所有再分发权利。

两个更大的真实入口分别超过 128 个目录和单文档 4096 个链接上限，均返回明确错误且未建立连接；失败记录分别保留在同日 `-a`、`-b` 验证目录中，不作为成功验收。

使用真实捕获元数据、只读桥接替身的无头浏览器验证覆盖 1440 中文浅色、900 英文深色的连接、目录选择和结果分页，共 6 张截图，无脚本错误或横向溢出。界面验证不产生工程写入、外部请求或原文件传输。
