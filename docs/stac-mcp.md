# 自定义栅格源的 MCP 与 Agent 接入

2026-10-05。MCP 已接入原生 STAC API、静态 Catalog、独立 Item 和公开栅格 URL 的目录、工程、下载及本地检查。软件内 Agent 已能读取已保存来源、搜索其目录、读取资产声明和已下载原值，并准备工程 / 下载审核计划；执行沿用原生卡片确认。

## 所有入口共用原生来源与任务

MCP 通过 `serve-mcp --data-dir` 独占自己的目录，或通过 `serve-mcp --server http://127.0.0.1:PORT` 连接明确运行中的本地服务。不能与桌面同时直接占用同一目录。默认只读；连接、搜索、保存工程、下载与移除连接都需要进程启动时的 `--allow-write`。搜索保存不可变元数据并消耗一次性游标，因此不能标成无副作用的只读工具。

| 工具 | 返回与行为 |
| --- | --- |
| `geod_stac_connections` | 分页读取本地来源概览，不联网 |
| `geod_stac_catalog` | 分页读取真实集合、目录节点或独立快照引用；分别标为 collection / directory / snapshot |
| `geod_stac_snapshot` | 读取原生快照、完整原始条目字段、资产和来源声明 |
| `geod_stac_assets` | 分页读取所有原资产声明，包括不支持的资产及原因 |
| `geod_stac_inspect` | 校验已完成原文件，读取 TIFF 原生网格 / 类型 / 声明；省略图片 |
| `geod_stac_pixel` | 按零起始行列读取原样本、NoData、精确大整数或非有限值 |
| `geod_stac_connect` | 连接明确选择的公开来源，返回本地来源标识和目录读取入口 |
| `geod_stac_search` | 读取一页真实结果，保存快照；返回每个条目标识、详情入口和完整翻页状态 |
| `geod_stac_project_save` | 由快照与原始资产键保存 / 追加工程，不传输文件 |
| `geod_stac_download` | 按工程引用排队或复用原文件，返回真实任务与轮询入口 |
| `geod_stac_forget` | 移除发现入口和游标，保留快照、工程与本地原件 |

搜索页保留所有原生返回身份，但较大的属性、足迹与资产声明用快照 / 资产工具另读，避免元数据撑大结果而丢失翻页标识。资产和目录页使用 `nextOffset`；搜索页使用原生 `nextCursor`，后续请求须保持来源、集合 / 目录、边界框、时间及页大小一致。空页有游标仍需继续；`complete` 与 `limitReached` 不互相替代，静态模式另返回累计 `scannedItems`。

静态目录的搜索选择使用原生保存的 URL 哈希 `key`，条目的 `collectionId` 保留真实上游标识。静态扫描按声明的 WGS84 边界框和时间做本地交集，不声称 STAC API 几何检索。独立 Item / 栅格来源从目录页获取快照，无需伪造搜索集合。

工程与下载只接受 `snapshotId` / `assetKey`，下载地址与字段由原生快照解析，不能用替换 `href`、账号密钥或输出路径改变计划。资产名不自动启用科学处理。现有公开同源元数据、512 MiB 原文件上限、无字节续传及通用科学处理限制保持原义，见[原生说明](custom-stac.md)。元数据大小、参数和结果也受 [MCP 限制](mcp.md)约束。

## 软件内 Agent 的当前范围

Agent 的工具集合新增六个 STAC 读取工具、一个元数据搜索工具和两项审核计划。搜索只使用软件已经连接的来源；模型不能连接 / 移除来源，也不能直接保存工程或排队下载。`geod_stac_project_plan` 和 `geod_stac_download_plan` 先生成审核卡片，分别确认后才能执行。来源列表标注 `agentRead`、`agentSearch`、`agentDownload` 与 `approvalRequired`；文件仍须通过原始声明、大小和稳定 ETag 检查。

Agent 搜索默认 5 个结果，最多 20 个；目录和资产页最多 20 个。原始来源网址、本地路径和凭据不发送到模型，原资产键、快照标识、类型、声明、限制与计数保留。来源文本仍是待解释的数据，不成为模型指令。现有九个固定公开源的审核计划与确认流程保留；这些条目不能混作固定源搜索结果。
