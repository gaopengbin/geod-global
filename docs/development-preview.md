## 优先试用的流程

1. 在探索页选择公开数据源，设定区域、日期并检索影像。
2. 选择多景，创建工程并下载；从工程返回探索页继续追加，再回到同一工程。
3. 查看下载任务、处理失败任务，在我的数据中打开本地缩略图、栅格检查和工作空间地图。
4. 按工程区域裁剪，或对支持的相同网格拼接；打开成果并点击地图读取原始像元。
5. 关闭后重新打开，检查工程、文件及缩略图恢复；托盘运行与退出继续使用软件内设置。

公开 Sentinel-2、Landsat、Copernicus DEM、NAIP、Sentinel-1 RTC 和已适配的 MODIS 产品都有具体真实文件验证。它们各自的处理范围不同，详见[数据源进度](provider-integration-status.md)。MODIS NDVI / EVI 的四文件联合质量筛选、完整统计及新景不合格时整组回退本次已核对；实际用户操作生成的六份成果与独立全值结果相同。

NASA Earthdata 和 Copernicus 账号入口已在设置中提供。当前没有用于正向验收的账号，HLS、SRTM、VIIRS 生产原包和 SAFE 的成功授权及完整原文件流程继续等待账号测试；公开目录与已明确验证的合成格式控制分别记录，不混作真实原包下载。
