## 打开程序

启动页现在是 AI 对话首页，沿用 GeoD Agent 输入框，支持模型连接、附件、执行确认和流式对话。首次打开没有默认样例区域，也不会自动检索；直接描述地点和任务即可由 Agent 解析。已有会话从历史入口打开，运行中的会话会继续显示。

首页的数据源看板保留探索页同一份注册表中的 15 个具体产品，并展示服务连接、本地二维导入和待接入候选，共 85 项。可以按影像、雷达、高程、专题栅格、地图、矢量、瓦片与本地文件分类，也可按产品系列或来源和接入状态组合筛选。哨兵汇集三个平台的 Sentinel-2 与 Sentinel-1 RTC；HLS 作为融合产品独立归类。无匹配时显示提示并支持重置，不会自动替换筛选。已接入卡片标明预览方式、原文件下载或授权状态，点击进入手动探索或连接表单；待接入卡片没有执行操作，不会搜索或下载。未选区域时，选区地图显示全球视图、坐标为空；选择范围或应用筛选后才检索。首页与地图侧栏切换会保留当前 Agent 草稿和附件。

看板卡片按“系列标识、平台、产品与能力”排列。Sentinel-1/2、MODIS 与 SRTM 使用本地官方任务或仪器图案，其他系列使用 GeoD 的文字与图标组合，不称为官方 Logo。平台名称独立展示，详情不重复平台文字。图片加载失败会退回系列标识，筛选与探索入口仍可用。素材来源、署名、文件校验值和使用范围见 [标识记录](../prototype/public/source-marks/README.md)。

在资源管理器双击 [GeoD Global 开发程序](../target/debug/geod-global-desktop.exe)。程序包含本地界面资源，无需另开网页服务或下载服务。开发期间需要实时更新界面时，在仓库运行 `npm run desktop:dev`。

需要更新可双击打开的开发程序时，使用 `npm run desktop:build`；它生成包含最新界面资源的调试程序，不制作安装包。单独执行默认 `cargo build` 不包含 `custom-protocol`，会生成依赖开发网页服务的程序，不能当作上述试用入口。

当前入口包含 OpenAI 原生 Responses 与加密推理恢复、附件存储管理及文本 / PDF / Office 文件上传、预览、引用和恢复，以及模型连接弹窗底部操作区修复。必要的引用保护、草稿保留及清理检查已通过。程序随开发更新；没有制作安装包或操作用户桌面。

Agent 方案卡片会跟随原生任务更新，区分执行中、输出收尾、失败和完成。文件大小未知时显示进度动效，不显示虚假的百分比；输出就绪后才显示成果入口。此次任务卡片的定向组件与隐藏浏览器检查采用受控状态，未新增模型调用或下载，真实业务验收范围仍以接入状态为准。

这是本机调试程序：Agent 使用本仓库的 `.agent-runtime/win32-x64/`，不是可脱离仓库分发的安装版。已有的真实接口成功、受控开发检查与外部失败状态从 [Agent 接入状态](agent-integration-status.md)查阅；原生窗口和安装环境仍需在发布阶段分别确认。

## 试用 Agent

在输入框点击回形针添加 PNG、JPEG 或 WebP，每张不超过 2 MiB，每条消息最多 3 张。点击预览可放大，发送失败保留草稿；重启后仍能在原对话继续提问。所选模型需要具备图片识别能力；本次真实识图验收只覆盖已记录的 GPT 网关配置。[图片输入说明](agent-images.md)列出存储和格式限制。

回形针现在也接受 UTF-8 的 TXT、Markdown、CSV、JSON 和 GeoJSON，每份最多 64 KiB，与图片合计每条消息最多 3 个附件。点击文件卡片可预览纯文本；发送失败保留草稿，重启和上下文整理后恢复引用。PDF 也可添加，每份不超过 2 MiB，须为未加密的 1 至 20 页文档；点击后按页预览，发送时保留原字节。所选模型和接口须支持 PDF。DOCX、XLSX 和 PPTX 也可添加，每份最多 2 MiB、未加密且不含宏；原文件发送须使用 OpenAI 原生 Responses 连接。内容预览不会执行公式或脚本。

音视频附件按用户决定暂缓，已有实验性代码保留，不属于当前试用和 Agent 接入验收范围，也不宣称完整可用。旧版 Office 等额外格式为后续候选，不加入本轮。本轮范围固定为既有图片、文档、地理数据读取、方案确认和任务执行，以及运行中和失败任务查询的补齐；两项待办已全部完成，完整清单见[接入状态](agent-integration-status.md)。

对话栏的“整理上下文”图标调用当前模型生成工作摘要，保留可见历史、图片和未发送草稿；过程中可以停止。运行时也会自动整理，原生待确认计划仍需用户单独确认。整理减少模型的工作上下文，不扩展本地会话存储上限。真实模型的一次连续测试完成 13 轮并触发两次自动整理，随后流式请求失败；另一次复测被接口以 400 拒绝。它们没有计为整段长会话通过。详情见[上下文整理说明](agent-context.md)。

## 优先试用的流程

1. 在探索页选择公开数据源，设定区域、日期并检索影像。
2. 选择多景，创建工程并下载；从工程返回探索页继续追加，再回到同一工程。
3. 查看下载任务、处理失败任务，在我的数据中打开本地缩略图、栅格检查和工作空间地图。
4. 按工程区域裁剪，或对支持的相同网格拼接；打开成果并点击地图读取原始像元。
5. 关闭后重新打开，检查工程、文件及缩略图恢复；托盘运行与退出继续使用软件内设置。

公开 Sentinel-2、Landsat、Copernicus DEM、NAIP、Sentinel-1 RTC 和已适配的 MODIS 产品都有具体真实文件验证。它们各自的处理范围不同，详见[数据源进度](provider-integration-status.md)。MODIS NDVI / EVI 的四文件联合质量筛选、完整统计及新景不合格时整组回退本次已核对；实际用户操作生成的六份成果与独立全值结果相同。

NASA Earthdata 和 Copernicus 账号入口已在设置中提供。当前没有用于正向验收的账号，HLS、SRTM、VIIRS 生产原包和 SAFE 的成功授权及完整原文件流程继续等待账号测试；公开目录与已明确验证的合成格式控制分别记录，不混作真实原包下载。
