# 商业规则设计附件

这些文件仅供[附件16](../16-Free-Pro-and-Usage-Design.md)评审和后续开发使用，没有接入客户端或账号服务，也不会开通付费功能。

- `catalog.proposed.json`：Free / Pro、服务点包、赠点规则、拟议报价 / 消耗门禁。价格为 USD 实验建议，所有商品不可购买。
- `source-entitlements.proposed.json`：当前 85 项目录的逐项服务包装建议，保留当前接入状态；记录来源文件 SHA256 和基线提交。未知类别默认复核，不自动放行。
- `source-entitlements.proposed.csv`：同一 85 项映射的可读分档表，可在表格软件查看。

映射中 18 项 Free 基础图源候选、14 项 Free 公共/自有连接、7 项 Free 本地格式、29 项 Pro 官方高级服务候选、10 项需许可复核、6 项需拆分具体产品、1 项自带授权的平台聚合候选。数字是设计分类，不是新增接入数量或当前可购买的会员权益。

`pro-service-candidate` 表示拟新增的官方聚合/托管服务包装；已有本地开源能力保持原有权利。基础图源候选里的待接入项依然待接入；不设影像采购、代购或转售商品。权益由实际执行有价值服务的官方后端控制，不能用本地会员开关保证开源功能不被修改。
